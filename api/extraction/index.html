    Structured Clinical Extraction¶

    Research abstraction aids

    These records are research data-abstraction aids. They are not clinical documentation, and every item needs human review against the source note before it is used. A missing item does not mean that something was not done. The note text reaches the configured LLM endpoint, so the endpoint must be appropriate for the data.

    Two stages turn clinical notes into structured, evidence-linked records that use one data model:

    Function One record per Content
    extract_document_records note The document type; for an imaging report the study that produced it; for a pathology report the procedure that produced its specimen; and the diagnoses, biomarkers, treatments, disease assessments, performance status, lab tests and counseling the note states.
    extract_patient_records patient Cancer diagnoses with site, histology, dates and stage; biomarkers; treatment lines and regimens with agents, dates and best response; tissue procedures; imaging history; lab tests; counseling, screenings and referrals; key dated events.

    Both accept the note table summarize_patients takes: patient_id, note_text and note_date, plus optional note_id (unique) and note_type (the record system's label, shown to the model as a hint). Without note_id, each note gets a stable id from a hash of its patient, date, type and text, and exact duplicate notes are kept once. Dates become YYYY-MM-DD; a missing date stays unknown.

    from matchminer_ai import load_default_preset
from matchminer_ai.patients import (
    extract_document_records,
    extract_patient_records,
    extraction_items,
)

config = load_default_preset()
config.remote["enabled"] = True
config.remote["server_urls"] = ["http://localhost:8000/v1"]

patients = extract_patient_records(notes, config=config, checkpoint_dir="ckpt/patients")
documents = extract_document_records(
    notes, config=config, patient_records=patients, checkpoint_dir="ckpt/documents"
)
items = extraction_items(documents)  # one row per extracted item

    The two stages are independent. Passing patient_records to the document stage lists each patient's known diagnoses (D1, D2, ...) in its prompts so that items can name the cancer they concern (cancer_ids), as the lung abstraction this generalizes did after its patient pass.

    Records¶

    Every record carries schema_version (mmai-clinical-extraction-v2; v1 records, built before lab tests and counseling were added on 2026-11-17, have neither list), its level, patient_id, the selected extensions, and items: one list per item type. A document record adds note_id, note_date, note_type, document_type and document_type_text; a patient record adds note_count, first_note_date, last_note_date, chunk_count and failed_chunks, and gives each item an item_id (D1, B2, T3, ...). record_json_schema(level) returns the JSON schema of a record.

    Every item has:

    • item_type and its fields (below). Text the note does not state is "", a choice it does not settle is not_stated (where the vocabulary has it), a list is [], and an integer is 0.
    • dates as {"value": "2024-03", "precision": "month", "source": ...}, with precision day, month, year or unknown (value null). source is document_text (written in the note), note_date (a report's own study or specimen whose date is not written gets the note's date), evidence_note_date (a performed patient-level study or procedure without a written date gets the date of the earliest note quoted: it was done on or before then) or unknown.
    • evidence: one to four exact quotes, each with the note's note_id, note_date and the start/end character offsets of the quote in the note's own text. The model writes the quotes; code locates each one in the note and keeps the note's own text at that span. The words must occur in order; only layout may differ (whitespace and line breaks, letter case, markdown emphasis and heading marks, list markers at the start of a line, typographic quotes and dashes), which a JSON answer cannot reproduce reliably. A paraphrased or invented quote is rejected.

    Lab tests cover blood, urine and other fluid tests, one item per test or panel per collection; serum tumor markers that follow a cancer (CEA, CA 19-9, PSA) stay biomarkers. Counseling covers counseling, care discussions, supportive-care screenings (such as distress or lymphedema screening) and referrals, one item per topic per encounter.

    Imaging studies, procedures, lab tests and counseling also record how they occurred. In a document record, relation is this_report (the study an imaging report reads, or the procedure that produced the specimen a pathology report examines), previously_performed (an earlier or outside study or procedure the note says was done) or planned; source_of_document is true for this_report. In both levels status is performed or planned. Procedures, biomarkers, treatments and events carry cancer_ids (patient level, and document level when patient_records is given). Disease assessments and performance status are properties of one note, so they are document-level only, as in the lung abstraction; their table date is the note date.

    An imaging report's record must include the study it reads, and a pathology report's the procedure that produced its specimens (relation this_report), or the answer is retried. Neither was extracted by the lung abstraction: it used the record system's scan type only to select reports, and it recorded a specimen's procedure only as biopsy or surgical excision.

    Sites, histologies, stages, regimens and biomarker names are text as written; they are not normalized. With ncit_agent_codes: true, each treatment also gets agents_ncit: every agent's NCIt concept from the bundled NCIt snapshot (exact name or synonym, then the snapshot's spelling rules), or nulls.

    Querying records¶

    extraction_items flattens document or patient records to one row per item with the same columns at both levels: patient_id, level, note_id, note_date, document_type, item_type, item_id, a uniform date, date_precision and date_source (the item's primary date, or the note date for a document's assessments), every item field (a date field x becomes x, x_precision and x_source), evidence and the complete item. Questions a workup review asks become DataFrame filters:

    import pandas as pd

items = extraction_items(documents)
studies = items[(items.item_type == "imaging_study") & (items.status == "performed")]
ct_chest = studies[(studies.modality == "ct")
                   & studies.body_regions.map(lambda regions: "chest" in regions)]
reference = pd.Timestamp("2024-04-01")
recent = ct_chest[(pd.to_datetime(ct_chest.date) <= reference)
                  & (pd.to_datetime(ct_chest.date) >= reference - pd.Timedelta(days=30))
                  & (ct_chest.date_precision == "day")]

procedures = items[items.item_type == "procedure"]
core_biopsies = procedures[procedures.procedure_type == "core_needle_biopsy"]
any_histology = procedures[procedures.procedure_group == "histologic_biopsy"]

    Filter by item_type first: fields of other item types are missing in those rows. A month- or year-precision date is not a day; a query must decide how to treat it, and an undated study mentioned in a note (previously_performed with an unknown date) was done on or before that note's date. These are documentation signals for review, not determinations that a test was or was not done. Extraction-Based Workup Checks compile guideline workup requirements into declarative queries that apply these rules, with deduplication of studies documented in several notes, in code.

    Validation, retries and failures¶

    Each request's answer is decoded under its JSON schema when the remote backend is enabled and structured_outputs is on, then validated in code: field types and vocabularies, other companions, dates, ids, cancer_ids, the report's own study or procedure, and every quote. A failed answer is retried with its problems named (the model revises its rejected answer when it was complete JSON), up to max_attempts, then once with thinking off (reasoning_off_fallback). When the last attempt's only problems are quotes not found in the note, the items left without a found quote are dropped and counted (partial); any other problem on the last attempt fails the note (document level) or skips the chunk (patient level, listed in failed_chunks). A request that fails in transport fails the note, or stops the patient so that a rerun resumes at that chunk.

    Requests are long: Nemotron 3.5 Super often reasons for 10,000-15,000 tokens before an answer, and a patient chunk's answer adds its quotes. Set remote.request_timeout (600 seconds in the default preset) to cover a whole completion on a busy server, for example 7,200 seconds; the shared endpoint pool retries a timed-out request from the start, so a timeout shorter than a completion never finishes.

    Returned DataFrames have extraction_status (complete, partial or failed), error, item_count and the record dict (None when failed). return_metadata=True adds the schema version, prompt and response-schema hashes, extensions, model metadata and every request's attempts (finish reason and problem codes, without note text; answers and reasoning only in debug mode). return_qc=True adds failed, partial and truncated counts.

    Patient-level chunking¶

    A patient's notes are read in date order, packed into chunks of patient_extraction.chunk_tokens tokens (a longer note is split with chunk_overlap_tokens overlap), as serial summarization reads them, but without sentence deduplication, so quotes stay exact. Each chunk's request shows the record so far (items with their ids, fields and the numbers of the notes that support them) and returns only the chunk's new and changed items; code merges them, adding each update's evidence to the item's earlier evidence. The lung abstraction instead asked for the whole running JSON again on every chunk, so its cost grew with the square of the record's length, and a later answer could silently drop an item. A chunk whose prompt, with the output reserve, would exceed context_tokens fails the patient rather than being truncated.

    Checkpoints¶

    With checkpoint_dir, the document stage appends each finished note to document_records.jsonl and the patient stage saves each patient after every chunk under patient_records/ (files named by a hash of the patient id). A rerun with unchanged notes, context and extraction contract (schema version, prompt, field guide, extensions and response schema) reuses complete and partial results and retries the rest. Checkpoints hold patient-derived text.

    Extensions¶

    Disease-specific item types and prompt guidance are added by extensions, selected by name in document_extraction.extensions and patient_extraction.extensions, without changing the core model. The packaged thoracic extension adds a smoking_history item (smoking_status, pack_years, quit_date) and the thoracic guidance of the lung abstraction: histology and biomarker examples, lobe and nodal-station sites, thoracic operations and EBUS-TBNA. New extensions are registered with register_extension(Extension(name, description, item_types, guidance)); their item types must not reuse a core name, list key or id prefix.

    matchminer_ai.patients.extraction ¶

    Structured clinical data extraction: document-level and patient-level records.

    Research abstraction aids, not clinical documentation: every record needs human review. :func:extract_document_records returns one record per note (its document type, the imaging study or specimen procedure behind a report, and the diagnoses, biomarkers, treatments, disease assessments and performance status it states); :func:extract_patient_records returns one record per patient from all of their notes (diagnoses, biomarkers, treatment lines, procedures, imaging history and key dated events).     @dataclass(frozen=True)
class ItemType:
    """One kind of extracted item.

    ``key`` is the record's list of these items and ``name`` one item's
    ``item_type``. ``levels`` are the record levels that extract it.
    ``occurrence`` items (imaging studies, procedures) say how they relate to
    the document (``relation``) or, at the patient level, whether they were
    performed or planned (``status``). ``linkable_levels`` are the levels whose
    items carry ``cancer_ids``: the patient-level ``D`` ids of the diagnoses
    they concern. ``primary_date`` names the field that dates an item for
    timeline queries (None: the document's note date). ``check`` adds
    item-specific validation and returns problem messages.
    """

    name: str
    key: str
    id_prefix: str
    description: str
    fields: tuple[Field, ...]
    levels: frozenset[str]
    occurrence: bool = False
    linkable_levels: frozenset[str] = frozenset()
    primary_date: str | None = None
    guidance: str = ""
    check: Callable[[dict], list[str]] | None = None
    max_items: int = 64

    def __post_init__(self):
        names = [f.name for f in self.fields]
        reserved = {"item_id", "item_type", "relation", "status", "cancer_ids",
                    "evidence", "source_of_document"}
        if len(set(names)) != len(names) or reserved & set(names):
            raise ValueError(f"{self.name}: duplicate or reserved field names")
        if not re.fullmatch(r"[A-Z]{1,3}", self.id_prefix):
            raise ValueError(f"{self.name}: id_prefix must be 1-3 capital letters")
        if not set(self.levels) <= set(LEVELS) or not self.levels:
            raise ValueError(f"{self.name}: levels must be a nonempty subset of {LEVELS}")
        for item_field in self.fields:
            if item_field.other_text is not None and item_field.other_text not in names:
                raise ValueError(f"{self.name}.{item_field.name}: unknown other_text field")
        if self.primary_date is not None and self.primary_date not in names:
            raise ValueError(f"{self.name}: unknown primary_date field")

    def field(self, name: str) -> Field:
        return next(f for f in self.fields if f.name == name)

    @dataclass(frozen=True)
class Vocabulary:
    """A closed list of codes.

    ``other`` names the escape code whose field needs a free-text value, and
    ``unknown`` the code a document that does not say uses (None when the
    vocabulary has no such code, as for list-valued fields whose empty list
    means "not stated").
    """

    name: str
    description: str
    terms: tuple[Term, ...]
    other: str | None = "other"
    unknown: str | None = "not_stated"

    def __post_init__(self):
        codes = [term.code for term in self.terms]
        if len(set(codes)) != len(codes):
            raise ValueError(f"Vocabulary {self.name} repeats a code")
        for special in (self.other, self.unknown):
            if special is not None and special not in codes:
                raise ValueError(f"Vocabulary {self.name} lacks its {special} code")

    @property
    def codes(self) -> tuple[str, ...]:
        return tuple(term.code for term in self.terms)

    def group(self, code: str) -> str | None:
        """The coarser group of ``code`` (None when the vocabulary has none)."""
        for term in self.terms:
            if term.code == code:
                return term.group
        raise KeyError(f"{code!r} is not a {self.name} code")

    def describe(self) -> str:
        """The codes and their meanings, one per line, for a prompt."""
        return "\n".join(f"      {t.code}: {t.description}" for t in self.terms)

    Extract one structured record from each clinical note.

    A research abstraction aid: records need human review and are not clinical documentation. Each note is one LLM request with the settings of config.document_extraction; the answer is decoded under the record's JSON schema (remote backends with structured_outputs), validated, and every evidence quote is located in the note's own text. An answer that fails is retried with the problems named (max_attempts, then once with thinking off when reasoning_off_fallback is on). When the last attempt's only problems are quotes not found in the note, the items left without any found quote are dropped and the record is partial.

    def extract_document_records(
    notes: pd.DataFrame,
    *,
    config: MMAIConfig | None = None,
    patient_records: pd.DataFrame | None = None,
    checkpoint_dir: str | Path | None = None,
    return_metadata: bool = False,
    return_qc: bool = False,
    progress_callback: Callable[[int, int], None] | None = None,
) -> pd.DataFrame | tuple:
    """Extract one structured record from each clinical note.

    A research abstraction aid: records need human review and are not clinical
    documentation. Each note is one LLM request with the settings of
    ``config.document_extraction``; the answer is decoded under the record's JSON
    schema (remote backends with ``structured_outputs``), validated, and every
    evidence quote is located in the note's own text. An answer that fails is
    retried with the problems named (``max_attempts``, then once with thinking
    off when ``reasoning_off_fallback`` is on). When the last attempt's only
    problems are quotes not found in the note, the items left without any found
    quote are dropped and the record is ``partial``.

    Parameters
    ----------
    notes : pd.DataFrame
        One row per note: ``patient_id``, ``note_text``, ``note_date`` (missing
        dates stay unknown) and optionally ``note_id`` (unique) and
        ``note_type`` (the record system's label, shown to the model as a hint).
        Without ``note_id`` each note gets a stable id from a hash of its
        patient, date, type and text.
    patient_records : pd.DataFrame, optional
        Output of :func:`extract_patient_records`. Its diagnoses are listed in
        each prompt so that items can name the cancers they concern
        (``cancer_ids``), as the lung abstraction did after its patient pass.
    checkpoint_dir : path, optional
        Each finished document is appended to ``document_records.jsonl`` there;
        a rerun reuses complete and partial records whose note, context and
        extraction contract are unchanged and retries failed ones. The file
        holds patient-derived text: keep it where the notes may be kept.
    return_metadata, return_qc : bool
        Also return a metadata dict (schema version, prompt and schema hashes,
        model metadata, per-document attempts) and a QC report.
    progress_callback : callable, optional
        Called as ``progress_callback(finished_notes, total_notes)`` before the
        first request and then every few seconds while requests run.

    Returns
    -------
    pd.DataFrame
        One row per note with text, in patient and date order:
        ``patient_id``, ``note_id``, ``note_date``, ``note_type``,
        ``document_type``, ``extraction_status`` (``complete``, ``partial`` or
        ``failed``), ``error``, ``item_count`` and ``record`` (the record dict;
        None when failed). :func:`extraction_items` flattens the records to one
        row per item.
    """
    resolved = config or load_default_preset()
    if not isinstance(resolved, MMAIConfig):
        raise TypeError("config must be an MMAIConfig instance or None.")
    frame, counts = normalize_notes(notes)
    extensions = resolve_extensions((getattr(resolved, SECTION, None) or {}).get("extensions") or [])
    extra_types = extension_item_types(extensions)
    item_types = item_types_for("document", extra_types)
    linking = patient_records is not None
    cancers = known_cancers(patient_records) if linking else {}
    schema = document_response_schema(extra_types, linking=linking)
    settings = section_settings(resolved, SECTION, "clinical_document_record", schema)
    template = load_prompt_text(PROMPT_FILE)
    guide = render_field_guide("document", extra_types, linking=linking)
    guidance = extension_guidance(extensions)
    limit = settings.values.get("max_document_characters", 200000)
    if type(limit) is not int or limit < 1:
        raise ValueError(f"{SECTION}.max_document_characters must be a positive integer")
    ncit_resource = settings.values.get(
        "ncit_resource", resolved.good_option_catalog.get("ncit_resource", "Thesaurus_26.07d.FLAT.zip")
    )
    contract = digest({
        "schema_version": SCHEMA_VERSION, "template": template, "guide": guide,
        "guidance": guidance, "schema": schema, "ncit": settings.ncit_agent_codes,
    })
    debug = resolved.debug_mode

    notes_list = [
        {"patient_id": r.patient_id, "note_id": r.note_id, "note_date": r.note_date,
         "note_type": r.note_type, "text": r.note_text}
        for r in frame.itertuples(index=False)
    ]
    contexts = {
        n["note_id"]: linking_block(cancers.get(n["patient_id"], [])) if linking else ""
        for n in notes_list
    }
    inputs = {
        n["note_id"]: digest([n["patient_id"], n["note_date"], n["note_type"], n["text"],
                              contexts[n["note_id"]]])
        for n in notes_list
    }
    path = Path(checkpoint_dir) / CHECKPOINT_FILE if checkpoint_dir is not None else None
    saved: dict[str, dict] = {}
    if path is not None and path.exists():
        for line in path.read_text(encoding="utf-8").splitlines():
            if not line.strip():
                continue
            entry = json.loads(line)
            if (
                entry.get("contract_sha256") == contract
                and entry.get("input_sha256") == inputs.get(entry.get("note_id"))
                and entry.get("extraction_status") in {"complete", "partial"}
            ):
                saved[entry["note_id"]] = entry

    outcomes: dict[str, dict] = {}
    attempts: dict[str, list] = {}
    pending = []
    for note in notes_list:
        note_id = note["note_id"]
        if note_id in saved:
            outcomes[note_id] = saved[note_id]
            attempts[note_id] = saved[note_id].get("attempts", [])
        elif len(note["text"]) > limit:
            outcomes[note_id] = {"extraction_status": "failed", "record": None,
                                 "error": f"document exceeds {SECTION}.max_document_characters"}
        else:
            pending.append(note)
    reused = len(saved)
    by_id = {n["note_id"]: n for n in notes_list}

    def messages(note):
        content = fill(template, {
            "field_guide": guide,
            "extension_guidance": f"\n{guidance}\n" if guidance else "",
            "linking": f"\n{contexts[note['note_id']]}" if contexts[note["note_id"]] else "",
            "note_date": note["note_date"] or "unknown",
            "note_type": note["note_type"] or "none",
            "note_text": note["text"],
        })
        return [{"role": "user", "content": content}]

    finished: list[str] = []

    def write(note_ids):
        if path is None or not note_ids:
            return
        path.parent.mkdir(parents=True, exist_ok=True)
        now = datetime.now(timezone.utc).isoformat(timespec="seconds")
        with path.open("a", encoding="utf-8") as handle:
            for note_id in note_ids:
                outcome = outcomes[note_id]
                handle.write(json.dumps({
                    "note_id": note_id, "patient_id": by_id[note_id]["patient_id"],
                    "schema_version": SCHEMA_VERSION, "contract_sha256": contract,
                    "input_sha256": inputs[note_id], **outcome,
                    "attempts": attempts.get(note_id, []), "completed_at": now,
                }, ensure_ascii=False) + "\n")

    model_metadata: dict[str, Any] = {}
    if pending:
        chunk_size, chunks_in_flight = settings.queue_shape
        queue = RequestQueue(
            get_llm_backend(resolved), settings.runtimes, chunk_size=chunk_size,
            chunks_in_flight=chunks_in_flight,
            model_metadata_cache_dir=resolved.model_metadata_cache_dir,
        )
        # Prompts are built as requests are sent, so a large run never holds
        # every rendered prompt at once.
        waiting = iter(pending)

        def feed():
            note = next(waiting, None)
            if note is not None:
                original = messages(note)
                queue.add((note["note_id"], 1, original), original, "main")

        for _ in range(2 * chunk_size * chunks_in_flight):
            feed()

        def record(item, answer, reasoning, finish_reason, provenance):
            note_id, attempt, original = item
            note = by_id[note_id]
            group = attempt_group(attempt, settings)
            entry = attempt_entry(attempt, group, finish_reason, provenance, debug=debug,
                                  answer=answer, reasoning=reasoning)
            attempts.setdefault(note_id, []).append(entry)
            if finish_reason == "error":
                entry["error"] = "request failed"
                outcomes[note_id] = {"extraction_status": "failed", "record": None,
                                     "error": "the LLM request failed after its transport retries"}
                finished.append(note_id)
                feed()
                return
            final = attempt >= settings.total_attempts
            try:
                value = parse_answer(answer, finish_reason)
            except ValueError as exc:
                check, error = None, str(exc)
            else:
                check, error = check_document_answer(
                    value, note, item_types, linking=linking,
                    known_ids={c["item_id"] for c in cancers.get(note["patient_id"], [])},
                ), None
            problems = [] if check is None else check.problems
            if error is None and not problems:
                status = "complete"
            elif error is None and final and not check.structural:
                status = "partial"
            else:
                entry["problems"] = [error] if error else [p.code for p in problems]
                if not final:
                    queue.add((note_id, attempt + 1, original),
                              retry_messages(original, answer, check is not None, problems, error),
                              attempt_group(attempt + 1, settings))
                    return
                outcomes[note_id] = {"extraction_status": "failed", "record": None,
                                     "error": "no valid answer after every attempt: "
                                     + "; ".join(entry["problems"][:5])}
                finished.append(note_id)
                feed()
                return
            built = build_document_record(note, value, check, item_types, extensions)
            if settings.ncit_agent_codes:
                add_ncit_codes(built, ncit_resource)
            outcome = {"extraction_status": status, "record": built, "error": None}
            if status == "partial":
                entry["problems"] = [p.code for p in check.grounding]
                outcome["dropped_items"] = check.dropped
                outcome["dropped_quotes"] = len(check.grounding)
            outcomes[note_id] = outcome
            finished.append(note_id)
            feed()

        def flush():
            write(finished)
            finished.clear()
            if progress_callback is not None:
                progress_callback(len(outcomes), len(notes_list))

        if progress_callback is not None:
            progress_callback(len(outcomes), len(notes_list))
        logger.info("Extracting document records for %d notes.", len(pending))
        model_metadata = queue.run(record, progress=flush)

    rows = []
    for note in notes_list:
        outcome = outcomes[note["note_id"]]
        built = outcome.get("record")
        rows.append({
            "patient_id": note["patient_id"], "note_id": note["note_id"],
            "note_date": note["note_date"], "note_type": note["note_type"],
            "document_type": built["document_type"] if built else None,
            "extraction_status": outcome["extraction_status"], "error": outcome.get("error"),
            "item_count": sum(map(len, built["items"].values())) if built else 0,
            "record": built,
        })
    result = pd.DataFrame(rows, columns=DOCUMENT_COLUMNS)
    statuses = result.set_index("note_id").extraction_status if len(result) else pd.Series(dtype=str)
    metadata = {
        "package": package_metadata(),
        "config_snapshot": config_snapshot(resolved),
        "schema_version": SCHEMA_VERSION,
        "contract_sha256": contract,
        "prompt_sha256": digest(template),
        "response_schema_sha256": digest(schema),
        "extensions": [e.name for e in extensions],
        "linking": linking,
        "structured_outputs": settings.structured,
        "model_metadata": model_metadata,
        "counts": {
            "documents": len(notes_list), "reused": reused,
            **{s: int((statuses == s).sum()) for s in ("complete", "partial", "failed")},
            **counts,
        },
        "documents": {
            n["note_id"]: {
                "extraction_status": outcomes[n["note_id"]]["extraction_status"],
                "attempts": attempts.get(n["note_id"], []),
                **{k: outcomes[n["note_id"]][k] for k in ("dropped_items", "dropped_quotes")
                   if k in outcomes[n["note_id"]]},
            }
            for n in notes_list
        },
    }
    outputs: list[Any] = [result]
    if return_metadata:
        outputs.append(metadata)
    if return_qc:
        truncated = [i for i, a in attempts.items() if any(e["finish_reason"] == "length" for e in a)]
        outputs.append(pd.DataFrame(qc_rows([
            ("documents_failed_extraction", list(statuses[statuses == "failed"].index)),
            ("documents_partial_extraction", list(statuses[statuses == "partial"].index)),
            ("documents_truncated_llm_response", truncated),
        ], len(notes_list))))
    return outputs[0] if len(outputs) == 1 else tuple(outputs)

    A research abstraction aid: records need human review and are not clinical
    documentation. Each patient's notes are read in date order in chunks of

    fails in transport stops that patient (``failed``); a rerun with the same

    Parameters
    ----------
    notes : pd.DataFrame
        One row per note: ``patient_id``, ``note_text``, ``note_date``, and

    return_metadata, return_qc : bool

    progress_callback : callable, optional
        Called as ``progress_callback(finished_chunks, total_chunks)`` before the
        first request and then every few seconds while requests run.

    Returns
    -------
    pd.DataFrame
        One row per patient: ``patient_id``, ``extraction_status``
        (``complete``, ``partial`` when a chunk failed or ungrounded items were
        dropped, or ``failed``), ``error``, ``note_count``, ``chunk_count``,
        ``failed_chunks``, ``item_count`` and ``record`` (None when failed).
    """

        raise TypeError("config must be an MMAIConfig instance or None.")
    frame, counts = normalize_notes(notes)
    extensions = resolve_extensions((getattr(resolved, SECTION, None) or {}).get("extensions") or [])
    extra_types = extension_item_types(extensions)
    item_types = item_types_for("patient", extra_types)
    schema = patient_response_schema(extra_types)
    settings = section_settings(resolved, SECTION, "clinical_patient_record_update", schema)
    values = settings.values
    chunk_tokens = values.get("chunk_tokens", 40000)
    overlap = values.get("chunk_overlap_tokens", 500)
    if type(chunk_tokens) is not int or chunk_tokens < 256:
        raise ValueError(f"{SECTION}.chunk_tokens must be an integer of at least 256")
    if type(overlap) is not int or not 0 <= overlap < chunk_tokens // 2:
        raise ValueError(f"{SECTION}.chunk_overlap_tokens must be from 0 to half of chunk_tokens")
    context = values.get("context_tokens")
    if context is None:
        context = values.get("local", {}).get("engine", {}).get("max_model_len")
    max_tokens = int(settings.runtime["sampling_params"].get("max_tokens", 0))
    tokenizer_name = settings.runtime.get("tokenizer_name", settings.runtime["model_name"])
    template = load_prompt_text(PROMPT_FILE)
    guide = render_field_guide("patient", extra_types)
    guidance = extension_guidance(extensions)
    ncit_resource = values.get(
        "ncit_resource", resolved.good_option_catalog.get("ncit_resource", "Thesaurus_26.07d.FLAT.zip")
    )
    contract = digest({
        "schema_version": SCHEMA_VERSION, "template": template, "guide": guide,
        "guidance": guidance, "schema": schema,
    })
    debug = resolved.debug_mode
    folder = Path(checkpoint_dir) / CHECKPOINT_SUBDIR if checkpoint_dir is not None else None

    patients = {
        str(pid): patient_note_list(group)
        for pid, group in frame.groupby("patient_id", sort=False)
    }
    inputs = {
        pid: digest({
            "notes": [[n["note_id"], n["note_date"], n["note_type"], digest(n["text"])] for n in ns],
            "chunk_tokens": chunk_tokens, "overlap": overlap, "tokenizer": tokenizer_name,
        })
        for pid, ns in patients.items()
    }
    states: dict[str, dict[str, Any]] = {}
    reused = 0
    for pid in patients:
        saved = None
        path = folder / f"{digest(pid)[:32]}.json" if folder is not None else None
        if path is not None and path.exists():
            candidate = read_json(path)
            if (
                candidate.get("patient_id") == pid
                and candidate.get("contract_sha256") == contract
                and candidate.get("input_sha256") == inputs[pid]
            ):
                saved = candidate
        if saved is not None:
            reused += saved["status"] in {"complete", "partial"}
            states[pid] = {
                "state": PatientState.from_json(item_types, saved["state"]),
                "next_chunk": saved["next_chunk"], "chunk_count": saved["chunk_count"],
                "failed_chunks": saved["failed_chunks"], "dropped": saved["dropped"],
                "attempts": saved["attempts"],
                "status": "running" if saved["status"] == "failed" else saved["status"],
                "error": None, "path": path,
            }
        else:
            states[pid] = {
                "state": PatientState(item_types), "next_chunk": 0, "chunk_count": None,
                "failed_chunks": [], "dropped": 0, "attempts": {}, "status": "running",
                "error": None, "path": path,

    chunks: dict[str, list[list[dict]]] = {}
    if pending:

        for pid in pending:
            chunks[pid] = pack_fragments(
                note_fragments(patients[pid], tokenizer, chunk_tokens - 64, overlap), chunk_tokens
            )
            states[pid]["chunk_count"] = len(chunks[pid])

    def save(pid):
        s = states[pid]
        if s["path"] is None:
            return
        atomic_json(s["path"], {
            "patient_id": pid, "schema_version": SCHEMA_VERSION, "contract_sha256": contract,
            "input_sha256": inputs[pid], "chunk_count": s["chunk_count"],
            "next_chunk": s["next_chunk"], "failed_chunks": s["failed_chunks"],
            "dropped": s["dropped"], "status": s["status"], "error": s["error"],
            "attempts": s["attempts"], "state": s["state"].to_json(),
        })

    def messages(pid):
        s = states[pid]
        index = s["next_chunk"]
        content = fill(template, {
            "field_guide": guide,
            "extension_guidance": f"\n{guidance}\n" if guidance else "",
            "record": s["state"].render(),
            "part": str(index + 1),
            "parts": str(s["chunk_count"]),
            "notes": render_chunk(chunks[pid][index]),
        })
        if context and max_tokens:
            prompt_tokens = len(tokenizer(content, add_special_tokens=False)["input_ids"])
            if prompt_tokens + max_tokens + 1024 > context:
                return None
        return [{"role": "user", "content": content}]

    def finish(pid):
        s = states[pid]
        s["status"] = "partial" if s["failed_chunks"] or s["dropped"] else "complete"
        save(pid)

    model_metadata: dict[str, Any] = {}
    if pending:
        chunk_size, chunks_in_flight = settings.queue_shape
        queue = RequestQueue(
            get_llm_backend(resolved), settings.runtimes, chunk_size=chunk_size,
            chunks_in_flight=chunks_in_flight,
            model_metadata_cache_dir=resolved.model_metadata_cache_dir,
        )

        def start(pid):
            """Queue the patient's next chunk, or finish the patient."""
            s = states[pid]
            if s["next_chunk"] >= s["chunk_count"]:
                finish(pid)
                return
            original = messages(pid)
            if original is None:
                s["status"] = "failed"
                s["error"] = (
                    f"part {s['next_chunk'] + 1}: the record so far and the notes exceed "
                    f"{SECTION}.context_tokens with the output reserve"
                )
                save(pid)
                return
            queue.add((pid, s["next_chunk"], 1, original), original, "main")

        def record(item, answer, reasoning, finish_reason, provenance):
            pid, index, attempt, original = item
            s = states[pid]
            group = attempt_group(attempt, settings)
            entry = attempt_entry(attempt, group, finish_reason, provenance, debug=debug,
                                  answer=answer, reasoning=reasoning)
            s["attempts"].setdefault(str(index), []).append(entry)
            if finish_reason == "error":
                s["status"] = "failed"
                s["error"] = f"part {index + 1}: the LLM request failed after its transport retries"
                save(pid)
                return
            final = attempt >= settings.total_attempts
            try:
                value = parse_answer(answer, finish_reason)
            except ValueError as exc:
                check, error = None, str(exc)
            else:
                check, error = check_patient_answer(value, chunks[pid][index], s["state"]), None
            problems = [] if check is None else check.problems
            accept = error is None and (not problems or (final and not check.structural))
            if not accept:
                entry["problems"] = [error] if error else [p.code for p in problems]
                if not final:
                    queue.add((pid, index, attempt + 1, original),
                              retry_messages(original, answer, check is not None, problems, error),
                              attempt_group(attempt + 1, settings))
                    return
                s["failed_chunks"].append(index)
            else:
                if problems:
                    entry["problems"] = [p.code for p in check.grounding]
                    s["dropped"] += len(check.dropped)
                s["state"].apply(check)
            s["next_chunk"] = index + 1
            save(pid)
            start(pid)

        def report():
            if progress_callback is not None:
                total = sum(s["chunk_count"] or 0 for s in states.values())
                finished = sum(
                    (s["chunk_count"] or 0) if s["status"] != "running" else s["next_chunk"]
                    for s in states.values()
                )
                progress_callback(finished, total)

        for pid in pending:
            start(pid)
        report()
        logger.info("Extracting patient records for %d patients.", len(pending))
        model_metadata = queue.run(record, progress=report)

    rows = []
    for pid, s in states.items():
        built = None
        if s["status"] != "failed":
            built = build_patient_record(
                pid, s["state"], patients[pid], chunk_count=s["chunk_count"],
                failed_chunks=s["failed_chunks"], extensions=extensions,
            )
            if settings.ncit_agent_codes:
                for item in built["items"].get("treatments", []):
                    item["agents_ncit"] = ncit_agent_codes(item["agents"], ncit_resource)
        rows.append({
            "patient_id": pid, "extraction_status": s["status"], "error": s["error"],
            "note_count": len(patients[pid]), "chunk_count": s["chunk_count"],
            "failed_chunks": list(s["failed_chunks"]),
            "item_count": sum(map(len, built["items"].values())) if built else 0,
            "record": built,
        })
    result = pd.DataFrame(rows, columns=PATIENT_COLUMNS)
    statuses = {pid: s["status"] for pid, s in states.items()}
    metadata = {
        "package": package_metadata(),
        "config_snapshot": config_snapshot(resolved),
        "schema_version": SCHEMA_VERSION,
        "contract_sha256": contract,
        "prompt_sha256": digest(template),
        "response_schema_sha256": digest(schema),
        "extensions": [e.name for e in extensions],
        "structured_outputs": settings.structured,
        "model_metadata": model_metadata,
        "counts": {
            "patients": len(states), "notes": int(len(frame)), "reused": reused,
            "chunks": sum(s["chunk_count"] or 0 for s in states.values()),
            **{k: sum(v == k for v in statuses.values()) for k in ("complete", "partial", "failed")},
            **counts,
        },
        "patients": {
            pid: {"extraction_status": s["status"], "attempts": s["attempts"],
                  "failed_chunks": s["failed_chunks"], "dropped_items": s["dropped"]}
            for pid, s in states.items()
        },
    }
    outputs: list[Any] = [result]
    if return_metadata:
        outputs.append(metadata)
    if return_qc:
        truncated = [
            pid for pid, s in states.items()
            if any(e["finish_reason"] == "length" for a in s["attempts"].values() for e in a)
        ]
        outputs.append(pd.DataFrame(qc_rows([
            ("patients_failed_extraction", [p for p, v in statuses.items() if v == "failed"]),
            ("patients_partial_extraction", [p for p, v in statuses.items() if v == "partial"]),
            ("patients_truncated_llm_response", truncated),
        ], len(states))))
    return outputs[0] if len(outputs) == 1 else tuple(outputs)

    def extraction_items(records: pd.DataFrame | list[dict]) -> pd.DataFrame:
    """One row per extracted item of document or patient records.

    ``records`` is the output of :func:`extract_document_records` or
    :func:`extract_patient_records` (its ``record`` column), or a list of record
    dicts. Columns: ``ITEM_COLUMNS``, then every field of the items (a date field
    ``x`` becomes ``x``, ``x_precision`` and ``x_source``), ``evidence`` and the
    complete ``item`` dict. Failed records (None) contribute no rows.
    """
    if isinstance(records, pd.DataFrame):
        if "record" not in records:
            raise ValueError("records must have a record column")
        values = list(records["record"])
    else:
        values = list(records)
    primary = _primary_dates()
    rows = []
    for record in values:
        if not isinstance(record, dict):
            continue
        document = record["level"] == "document"
        for items in record["items"].values():
            for item in items:
                row = {
                    "patient_id": record["patient_id"],
                    "level": record["level"],
                    "note_id": record.get("note_id"),
                    "note_date": record.get("note_date"),
                    "document_type": record.get("document_type"),
                    "item_type": item["item_type"],
                    "item_id": item.get("item_id"),
                }
                date_field = primary.get(item["item_type"])
                if date_field is not None and isinstance(item.get(date_field), dict):
                    when = item[date_field]
                    row.update(date=when["value"], date_precision=when["precision"],
                               date_source=when["source"])
                elif document and record.get("note_date"):
                    row.update(date=record["note_date"], date_precision="day",
                               date_source="note_date")
                else:
                    row.update(date=None, date_precision="unknown", date_source="unknown")
                for name, value in item.items():
                    if name in {"item_type", "item_id", "evidence"}:
                        continue
                    if isinstance(value, dict) and {"value", "precision", "source"} <= set(value):
                        row[name] = value["value"]
                        row[f"{name}_precision"] = value["precision"]
                        row[f"{name}_source"] = value["source"]
                    else:
                        row[name] = value
                row["evidence"] = item["evidence"]
                row["item"] = item
                rows.append(row)
    frame = pd.DataFrame(rows)
    if frame.empty:
        return pd.DataFrame(columns=[*ITEM_COLUMNS, "evidence", "item"])
    rest = [c for c in frame.columns if c not in ITEM_COLUMNS and c not in {"evidence", "item"}]
    return frame[[*ITEM_COLUMNS, *rest, "evidence", "item"]]

    def record_json_schema(level: str, extra: Iterable[ItemType] = ()) -> dict:
    """The JSON schema of the records :func:`extract_document_records` (``level``
    ``"document"``) or :func:`extract_patient_records` (``"patient"``) return."""
    items = {
        t.key: {"type": "array", "items": item_record_schema(t, level)}
        for t in item_types_for(level, extra)
    }
    common = {
        "schema_version": {"const": SCHEMA_VERSION},
        "level": {"const": level},
        "patient_id": {"type": "string"},
        "extensions": {"type": "array", "items": {"type": "string"}},
    }
    if level == "document":
        specific = {
            "note_id": {"type": "string"},
            "note_date": {"type": ["string", "null"]},
            "note_type": {"type": ["string", "null"]},
            "document_type": {"type": "string", "enum": list(v.DOCUMENT_TYPES.codes)},
            "document_type_text": {"type": "string"},
        }
    else:
        specific = {
            "note_count": {"type": "integer"},
            "first_note_date": {"type": ["string", "null"]},
            "last_note_date": {"type": ["string", "null"]},
            "chunk_count": {"type": "integer"},
            "failed_chunks": {"type": "array", "items": {"type": "integer"}},
        }
    schema = _object({**common, **specific, "items": _object(items)})
    schema["$schema"] = "https://json-schema.org/draft/2020-12/schema"
    schema["title"] = f"MatchMiner-AI {level} extraction record ({SCHEMA_VERSION})"
    return schema

    def register_extension(extension: Extension, *, replace: bool = False) -> None:
    """Make ``extension`` selectable by name. Its item types must not reuse a core
    item type's name, list key or id prefix."""
    if extension.name in _REGISTRY and not replace:
        raise ValueError(f"Extension {extension.name!r} is already registered")
    core = {(t.name, t.key, t.id_prefix) for t in CORE_ITEM_TYPES}
    taken = {value for triple in core for value in triple}
    for item_type in extension.item_types:
        if {item_type.name, item_type.key, item_type.id_prefix} & taken:
            raise ValueError(f"{item_type.name} reuses a core item type's name, key or prefix")
    _REGISTRY[extension.name] = extension
