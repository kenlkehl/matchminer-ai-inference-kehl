    Good Option Catalog and Scoring¶

    Good Option scoring asks whether a trial's experimental drugs have evidence behind them for one patient. The score ranks patient-trial pairs for human review; it is not an eligibility determination, a response probability, or a treatment recommendation. It has two separate, versioned stages: a patient-free catalog of drug and drug-class evidence, built once from a list of trials, and patient scoring against that catalog.

    from matchminer_ai.trials import build_good_option_catalog
from matchminer_ai.matching import check_good_options

# Patient-free research stage; run once before patient scoring.
catalog = await build_good_option_catalog(nct_ids, "drug_catalog", config=config)

# candidate_pairs: patient_id, trial_id, cancer_history_summary
scores = check_good_options(candidate_pairs, catalog="drug_catalog", config=config)

    check_good_options is the supported entry point for scoring; see On-demand check. How the Good Options pipeline works walks through every stage in order.

    Privacy boundary. Catalog construction receives NCT IDs and drug names only, and its searches never receive patient text, so it may run against a shared endpoint. Scoring sends the patient's cancer-history summary to the configured llm_good_option endpoint; use an endpoint authorized for the sensitivity of that input.

    Catalog code is in trials/drug_catalog.py (build, validation, loading), trials/drug_research.py (evidence sources) and trials/drug_evidence.py (data models); scoring is in matching/good_options.py. The matchminer_ai.good_options namespace re-exports the same names.

    Prompt resources¶

    All templates are bundled under src/matchminer_ai/prompts/:

    Files Purpose
    trial_drug_screen.system.txt, .user.txt, .retry.txt Identify anticancer agents and classify their roles in each trial.
    trial_drug_class.system.txt, .user.txt, .retry.txt Assign each drug to pharmacologic classes.
    trial_drug_synthesis.system.txt, .delta.txt, .delta_retry.txt Synthesize passage-grounded drug and class evidence one chunk at a time, returning only new or revised facts.
    llm_good_option.system.txt, .user.txt, .rubric.txt, .retry.txt Apply the four-criterion patient-drug rubric and correct invalid responses.
    good_option_checker_template.txt Patient-drug input for the deprecated GoodOptionChecker classifier.

    The catalog-build templates are listed in CATALOG_PROMPTS; catalog_prompts_sha256() fingerprints their text for checkpoint reuse and the catalog manifest.

    Build the catalog¶

    build_good_option_catalog(nct_ids, output_path, ...) is a coroutine. It fetches each trial's current ClinicalTrials.gov record, screens its interventions, researches every unique drug and drug class, synthesizes the evidence, and writes and validates a Parquet bundle at output_path, returning the loaded GoodOptionCatalog.

    Parameter Default Meaning
    nct_ids required NCT IDs, normalized and deduplicated in order.
    output_path required Catalog directory. An existing one raises FileExistsError unless overwrite=True.
    config default preset Uses llm_good_option and good_option_catalog.
    settings ResearchSettings() Source caps, facets, axes, retries and timeouts for research.
    sources default_sources() Evidence adapters implementing DrugEvidenceSource.
    web_provider DDGSWebProvider() General-web search provider (GeneralWebProvider).
    role_resolver, synthesizer, class_resolver LLM stages Callables that replace intervention screening, evidence synthesis, or class assignment.
    checkpoint_path <output>_checkpoints Checkpoint directory; must not contain or sit inside the output.
    reset_checkpoint False Discard a recognized checkpoint directory before starting.
    overwrite False Replace an existing catalog.
    progress_callback None Called as (stage, completed, total, label); stages are ctgov, screening, research, classify, class_research, class_synthesis, synthesis.
    subject_concurrency 1 Drugs, then classes, researched at once.
    web_search_concurrency 12 General-web searches in flight across all subjects.
    host_requests_per_second None Per-host request rates; override good_option_catalog.host_requests_per_second.
    ncbi_api_key_file None File holding an NCBI API key for PubMed; overrides good_option_catalog.ncbi_api_key_file and NCBI_API_KEY.
    llm_batch_size None Trials screened, and drugs classified, at once; overrides screening_checkpoint_batch_size and class_checkpoint_batch_size.

    The last five parameters only schedule work. They are left out of the checkpoint fingerprint, so a build can resume with different values.

    Intervention screening¶

    The configured LLM reads every DRUG, BIOLOGICAL, and COMBINATION_PRODUCT entry in its trial and arm context and keeps only concrete named agents with direct anticancer treatment intent. Antitumor medicines, biologics, cell and gene therapies, therapeutic radiopharmaceuticals, and named anticancer comparators are kept. Supportive and procedural medicines (including toxicity protection and GVHD prophylaxis unless the trial uses them as anticancer therapy), anesthetics, hemostatic agents, diagnostic tracers, devices, prevention-only agents, dosing or cohort labels, and unnamed standard-of-care placeholders are excluded, failing closed.

    • Decisions: research_disposition is one of INTERVENTION_SCREENING_DISPOSITIONS (include, exclude, uncertain); an excluded entry gets one of INTERVENTION_EXCLUSION_CATEGORIES (such as supportive_or_procedural, diagnostic_or_imaging, unspecified_standard_of_care).
    • Roles: each kept agent is investigational, uncertain, control, background (given the same way to every participant), or supportive. An agent given only in a comparator arm is control. Only investigational and uncertain drugs are scored.
    • Names: each agent is one drug named by the entry's own text (ctgov name, aliases, description, or its arms' descriptions), or a component of a regimen named there. "Pemetrexed + Cisplatin /Carboplatin" is three agents, and a standard acronym such as FOLFIRI is expanded into fluorouracil, leucovorin, and irinotecan, with the acronym in regimen_names. Agents are named by generic name (INN/USAN) or development code, never by a treatment category; an abbreviation, misspelling, or brand name that a generic name replaces ("LV", "5-Flurouracil") is listed in regimen_names the same way.
    • Grounding: a name of three or more letters and digits may be any part of the entry's text with spacing and punctuation removed; a two-character name ("SG", "LV") must be whole words of it, and a single character a whole field. Validation rejects agent names absent from the text unless a listed regimen or spelling covers them, and rejects a regimen name listed as an agent. A listed regimen name the text does not contain is dropped with a logged count and grounds no agent. A combination-spelled or ungrounded name gets one more attempt.
    • Structured output: with a remote backend the answer is decoded under INTERVENTION_SCREENING_JSON_SCHEMA (good_option_catalog.structured_outputs).

    build_intervention_screening_messages renders the screening prompt for one trial (build_role_resolution_messages is an alias). Every decision is kept in trial_intervention_screening.parquet: disposition, exclusion category, confidence, role, rationale, the supported agent names (active_entity_names_json), and the regimen names (regimen_names_json). Excluded entries never enter trial_drug_index.parquet, research, or synthesis.

    Drug identity¶

    Kept agents are normalized with the bundled NCI Thesaurus snapshot (good_option_catalog.ncit_resource, Thesaurus_26.07d.FLAT.zip) and deduplicated across the run. A name, its parenthetical-free form, or a parenthetical alone that is an exact NCIt name or synonym wins. Otherwise NCIThesaurusDrugIndex.resolve_drug_name accepts a concept only when one rule finds exactly one, in order: the same drug_name_key (case, spacing, separators, salt abbreviations, isotope notation, liposome word order); the same key without salts (the parent molecule when salts tie); route, dosage-form and biosimilar words moved or dropped; one misspelled word of eight or more letters corrected. A matched drug's drug_id is NCIT:<code>; an unmatched drug's is NAME: plus a hash of its drug_name_key.

    Research¶

    Each unique drug is researched once on five facets (FACETS: mechanism_targets, efficacy_by_tumor, biomarker_prevalence, biomarker_directed_efficacy, safety) from seven sources (default_sources(): ClinicalTrials.gov, PubMed, Europe PMC, CIViC, DailyMed, cancer.gov, and full-text general web). General-web queries include the phrase cancer treatment to reduce name collisions. Technical failures are retried with Retry-After or exponential backoff, and successful empty results stay distinct from exhausted technical failures. A drug whose every source failed on some facet is research_status="blocked" and is never synthesized.

    Retrieval runs on three axes, recorded per passage in query_scope:

    • Drug (drug): the agent's own name and aliases, all five facets, three adaptive rounds.
    • Indication (drug_indication, class_indication): efficacy by tumor, biomarker prevalence, and biomarker-directed efficacy with a disease as a required clause. The diseases are the conditionsModule.conditions of the trials the drug (or a class's member drugs) appears in, taken round-robin across trials, so the axis stays patient-free and cacheable. max_indication_passages_per_drug bounds a drug's indication passages, interleaved across diseases, sources, and facets.
    • Class (class): the pharmacologic class's name and aliases, once per class rather than once per drug, so agents that share a class share a corpus.

    Only PubMed, Europe PMC, cancer.gov, and general web run on the indication and class axes; the ctgov, label, and curation adapters search by exact agent name. Their settings live on ResearchSettings: indication_terms_per_drug and class_indication_terms (25 each), indication_facets, indication_sources, class_facets, class_sources, class_research_rounds (1), and the max_* record caps. Research settings are part of the checkpoint fingerprint.

    Research requests to ClinicalTrials.gov, DailyMed, and the NCBI E-utilities are paced per host across every subject; see good_option_catalog for the default rates.

    Drug classes¶

    A classify stage between research and synthesis assigns classes from the bundled NCIt hierarchy. A class is an NCIt concept above a drug concept, in the Pharmacologic Substance branch, other than the fixed NCIT_UMBRELLA_CLASSES (Pharmacologic Substance, Antineoplastic Agent, Enzyme Inhibitor, and the like); the chemical-structure branch is not used.

    • NCIt-matched drugs get every class above their concept, in code. A local search of NCIt class names and synonyms against the drug's name, definition, and mechanism passages finds up to class_candidate_limit (25) candidates, and the LLM may add, by code, those the passages show the drug belongs to. An added class brings its NCIt ancestors; codes outside the candidates are rejected; hierarchy classes are never removed. A drug with no candidates gets no LLM call.
    • Drugs NCIt leaves unclassified get their classes from the LLM: candidates, or a new class (class_source="llm") only where none fits. A new class's class_id is a hash of its normalized name, so "PD-L1 inhibitor" and "PD-L1 Inhibitors" share one corpus, and a new name that spells an NCIt class is stored as that class.
    • Limits: class_max_per_drug (3) caps the classes the LLM adds or names per drug. Only the drug's record and its candidates' names and short definitions enter the prompt, decoded under DRUG_CLASS_JSON_SCHEMA with a remote backend.

    An NCIt class's class_id is NCIT:<code>, its name NCIt's display or preferred name, and its aliases NCIt synonyms. Assignments are stored in drug_classes.parquet with ncit_code, class_source (ncit or llm), and assigned_by (ncit_hierarchy, llm_added_ncit, llm_added_ncit_ancestor, or llm_new); only LLM-chosen rows carry a basis (target, mechanism, or modality), target, confidence, and support IDs.

    Synthesis and stored summaries¶

    The configured LLM synthesizes each class's and each drug's passages into structured facts in six categories (mechanism_and_targets, efficacy_by_tumor, biomarker_prevalence, biomarker_directed_efficacy, safety, limitations), reading the corpus in chunks of synthesis_chunk_max_tokens (drugs) or class_evidence_max_tokens (classes), 60,000 each. Each chunk returns only new or revised facts, which code merges into the facts so far.

    • Citations: every fact cites passage support IDs, validated in code. A matched NCIt definition is stored as its own citable passage.
    • Scope: every fact carries scope agent or class, assigned in code from the corpus it was synthesized from, so the rubric's preference for agent-specific evidence has something to bind to.
    • Evidence levels: supported evidence is kept at every maturity level (ontology, preclinical, first-in-human, phase 1, ctgov, and mature clinical evidence) and labelled, without requiring approval, randomization, publication, or mature outcomes.
    • Retries: token-limited, blank, or invalid responses are retried with the validation error, up to synthesis_max_attempts (3). The default synthesis completion budget is 100,000 tokens (synthesis_llm); if every ordinary attempt is token-limited, the final attempt disables thinking.

    Each drug row in drug_summaries.parquet stores the facts (structured_facts_json) and two plain-text renders: good_option_summary, without safety, and help_me_choose_summary, the same render with safety, sized by good_option_summary_max_tokens and help_me_choose_summary_max_tokens. Each class row in class_summaries.parquet stores its facts and class_option_summary. URLs, queries, source labels, ctgov metadata, and failure notices stay in the internal tables and never appear in a patient-bearing prompt.

    Checkpoints and validation¶

    Catalog publication and its intermediate JSON checkpoints are atomic. Completed ctgov fetches, intervention screens, drug research, class assignments and research, and syntheses are reused when the same build is restarted; technically blocked fetches are retried. The checkpoint manifest fingerprints the NCT list, research settings and sources, the NCIt resource and version, the text of the catalog prompts, any custom resolver callables, and the llm_good_option and good_option_catalog sections (minus the pacing keys). An incompatible checkpoint fails explicitly instead of mixing evidence generations; pass checkpoint_path to use another directory or reset_checkpoint=True to discard it.

    validate_good_option_catalog(path) verifies file hashes and the compatibility_id, screening decisions, trial-drug references, terminal research and synthesis states, query scopes, fact scopes, and that every fact's support IDs exist for its drug or class. It returns the manifest. load_good_option_catalog(path, validate=True, cache=False) validates by default; with cache=True it keeps the catalog in memory until any bundle file's size or modification time changes.

    Command line¶

    matchminer-ai-build-good-option-catalog builds and validates a complete catalog, drug classes included, against one or more OpenAI-compatible endpoints:

    matchminer-ai-build-good-option-catalog \
  --nct-ids-file trial_ids.txt \
  --output good_option_catalog \
  --server-url http://localhost:8000/v1

    The served model is read from the endpoint's /v1/models (every server must report the same one), and its registered sampling profile (see LLM Server Helper) is applied to llm_good_option and every good_option_catalog.*_llm stage override. Rerun the same command to resume. The command prints the request rates it uses and whether an NCBI key is set, never the key.

    Score patient-trial pairs¶

    check_good_options, score_good_options_with_llm, and evaluate_good_options take a candidate_pairs DataFrame with patient_id, trial_id, and cancer_history_summary (the training names pseudo_mrn, nct_id, and patient_summary are also accepted). Pairs are deduplicated on patient_id and trial_id. The scorers other than check_good_options require a loaded GoodOptionCatalog.

    The prompt contains the patient's cancer-history summary first, then evidence for the trial's scoreable drugs (investigational or uncertain). Control, background, and supportive drugs are indexed but never scored. After the per-drug sections the prompt carries one labelled DRUG CLASS EVIDENCE block per distinct class across those drugs, naming which drugs each block covers; two drugs sharing a class produce one block.

    The rubric awards each scoreable drug up to four binary points (RUBRIC_CRITERIA):

    1. disease_type_benefit: evidence of human benefit in the patient's disease type, from the drug or its class (0 when the patient has already received or is receiving the drug);
    2. common_biomarker_in_disease: the targeted biomarker is present in 20% or more of that disease;
    3. patient_biomarker_targeted: the patient's tumor is documented to have the targeted biomarker; and
    4. biomarker_targeted_benefit: human evidence of benefit from targeting that biomarker.

    The code-derived score is total_points / (4 * scoreable_drug_count). parse_good_option_response validates an answer: it must assess exactly the supplied drugs (names compared without case), with each point the integer 0 or 1 and a non-empty rationale. Trials with missing catalog data, exhausted research, or missing synthesis are returned unscored; there is no live-search fallback.

    Column Content
    patient_id, trial_id The pair (trial_id normalized).
    good_option_score Points over maximum points; NaN when unscored.
    good_option_points, good_option_max_points Points earned and 4 * good_option_drug_count.
    good_option_drug_count Scoreable drugs in the trial.
    good_option_status ok, parse_failed, missing_catalog_trial, trial_ctgov_blocked, no_scoreable_drug, missing_drug_summary, or drug_research_blocked.
    good_option_method llm (classifier for the deprecated checker).
    good_option_patient_disease_type The model's statement of the patient's disease.
    good_option_drug_assessments Per drug: drug_name, targeted_biomarkers, and each criterion's point and rationale.
    good_option_uncertainties The model's key uncertainties.

    With debug_mode, each row also carries good_option_answer_text, good_option_reasoning_text, good_option_finish_reason, good_option_parse_error, good_option_parse_attempts (requests sent for the pair), good_option_reasoning_off_fallback_used, and good_option_evidence_packing. With return_metadata=True the metadata records the config snapshot, the catalog's compatibility_id, an evidence-packing summary (granularity counts and truncated subjects), the rubric criteria, and the retry settings.

    score_good_options_with_llm retries only invalid answers: max_parse_attempts (default 1) attempts in total, each retry carrying the previous answer and the validator's exact error, then one attempt with thinking disabled when reasoning_off_fallback=True. An answer stopped by its token limit counts as invalid. evaluate_good_options dispatches to it with method="llm" (the default).

    Evidence packing¶

    The catalog's stored renders are fixed-size. The scoring prompt does not use them; pack_good_option_evidence re-renders every drug and class from its stored structured facts, sized to how much evidence the trial has in total:

    1. good_option_evidence_budget takes the scoring model's context window (good_option_prompt.context_tokens, or llm_good_option.local.engine.max_model_len when unset), subtracts the active backend's llm_good_option max_tokens completion allowance, safety_tokens, room for a parse retry, and the fixed prompt text, and converts the rest at chars_per_token (3.5, conservative for the default Nemotron 3.5 Super and for Gemma 4). With the default preset that leaves about 530,000 characters, or about 700,000 under check_good_options' 50,000-token output cap.
    2. Drugs and classes share it by weighted max-min fair share, drugs at twice a class's weight. A subject needing less than its share releases the rest. max_drug_section_tokens and max_class_section_tokens (20,000 each) bound any one subject.
    3. A subject that fits its share is rendered in full. One that does not steps down to condensed (attribution capped at 160 characters, statements at 300) or brief (100 and 160) if that fits, so every fact stays visible; the space saved is offered to the others. EVIDENCE_GRANULARITIES defines the levels.
    4. Only when even brief overflows are facts dropped, by the render's ranking (strongest evidence first, tumor types interleaved) with an omission count; the survivors keep condensed detail so their numbers survive.

    Subjects without stored facts, such as hand-built summaries, fall back to their stored render, truncated if needed. A trial whose budget leaves under 1,000 characters per subject raises ValueError. build_good_option_messages returns the packed prompt for one patient and one trial's drug and class evidence.

    On-demand check¶

    check_good_options(candidate_pairs, *, catalog, config=None, return_metadata=False) wraps score_good_options_with_llm with the settings of the good_option_check preset section, applied to a copy of the config. The caller's config, and the llm_good_option section that fingerprints catalog builds, are left unchanged.

    • Catalog: a loaded GoodOptionCatalog or a bundle path. A path is loaded with load_good_option_catalog(path, cache=True), which validates once and reuses the catalog until any bundle file changes.
    • Output cap: the llm_good_option completion is capped at max_output_tokens (50,000), leaving more of the context for evidence.
    • Context: unless good_option_prompt.context_tokens is set, a remote OpenAI-compatible backend sizes the evidence to the smallest max_model_len its servers report at /v1/models (discover_context_tokens, discovery_timeout_seconds). If the lookup fails, packing uses the configured context and returns the warning.
    • Retries: invalid answers get max_parse_attempts (3) attempts in total, then one with thinking disabled when reasoning_off_fallback is true.

    Output columns match score_good_options_with_llm. With return_metadata=True, metadata["good_option_check"] also reports max_output_tokens, context_tokens, context_source (configured, endpoint, or preset), and context_warning.

    Deprecated: GoodOptionChecker¶

    The trained four-logit GoodOptionChecker classifier is deprecated. It saw one patient summary and one drug summary per example, never the class evidence the LLM prompt carries, and no checker artifact is published. score_good_options, evaluate_good_options(method="classifier"), and build_good_option_checker_text still run but emit DeprecationWarning; the good_option_checker preset section remains only so existing configs load.

    async def build_good_option_catalog(
    nct_ids: Sequence[str],
    output_path: str | Path,
    *,
    config: MMAIConfig | None = None,
    settings: ResearchSettings | None = None,
    sources: Sequence[DrugEvidenceSource] | None = None,
    web_provider: GeneralWebProvider | None = None,
    role_resolver: RoleResolver | None = None,
    synthesizer: SummarySynthesizer | None = None,
    class_resolver: ClassResolver | None = None,
    checkpoint_path: str | Path | None = None,
    reset_checkpoint: bool = False,
    overwrite: bool = False,
    progress_callback: Callable[[str, int, int, str], None] | None = None,
    subject_concurrency: int = 1,
    web_search_concurrency: int = 12,
    host_requests_per_second: Mapping[str, float] | None = None,
    ncbi_api_key_file: str | Path | None = None,
    llm_batch_size: int | None = None,
) -> GoodOptionCatalog:
    """Screen and research cancer-treatment agents with public-only checkpoints.

    ``subject_concurrency`` drugs (and later classes) are researched at once.
    It and ``web_search_concurrency`` only schedule work, so they are left out
    of the checkpoint fingerprint and may change between resumed runs. So do
    ``host_requests_per_second``, which paces each host across every subject
    and every stage, and ``ncbi_api_key_file``, which unlocks NCBI's higher
    E-utilities rate for the built-in PubMed source; both override their
    ``good_option_catalog`` keys (see :func:`catalog_research_pacing`).

    With a remote backend, each trial is screened and each drug classified on
    its own, checkpointed as soon as it finishes, with up to
    ``good_option_catalog.screening_checkpoint_batch_size`` trials and
    ``class_checkpoint_batch_size`` drugs in flight; the endpoint pool still
    caps the requests each server runs. A local engine, which batches prompts
    itself and is not thread-safe, gets groups of those sizes instead.
    ``llm_batch_size`` replaces both sizes for this run. Remote or local, each
    trial and drug gets its own prompts, retries and checkpoint, recorded in
    input order, so the sizes only schedule: the override is left out of the
    fingerprint like ``subject_concurrency`` and may change between resumed
    runs. The two keys themselves stay in it, as they always were.
    """

    normalized_ids = tuple(dict.fromkeys(normalize_nct_id(value) for value in nct_ids))
    if not normalized_ids:
        raise ValueError("At least one NCT ID is required to build a catalog.")
    output = Path(output_path).expanduser().resolve()
    if output.exists() and not overwrite:
        raise FileExistsError(f"Catalog output already exists: {output}")
    resolved_config = config or load_default_preset()
    resolved_settings = settings or ResearchSettings()
    # The section the checkpoint fingerprint hashes, so that a value set on it
    # takes effect; a copy, so the batch-size override stays out of the hash.
    catalog_config = dict(resolved_config.good_option_catalog)
    if llm_batch_size is not None:
        for stage in ("screening", "class"):
            catalog_config[f"{stage}_checkpoint_batch_size"] = llm_batch_size
    ncit_resource = str(catalog_config.get("ncit_resource") or "")
    ncit_version = str(catalog_config.get("ncit_version") or "unknown")
    if not ncit_resource:
        raise ValueError("GoodOption catalog configuration is missing ncit_resource.")
    ncit_index = load_ncit_drug_index(ncit_resource)
    host_rates, api_key = catalog_research_pacing(
        resolved_config,
        host_requests_per_second=host_requests_per_second,
        ncbi_api_key_file=ncbi_api_key_file,
    )
    resolved_sources = tuple(
        sources or default_sources(web_provider, ncbi_api_key=api_key)
    )
    resolved_checkpoint_path = (
        Path(checkpoint_path).expanduser().resolve()
        if checkpoint_path is not None
        else output.with_name(f"{output.name}_checkpoints")
    )
    if (
        resolved_checkpoint_path == output
        or resolved_checkpoint_path.is_relative_to(output)
        or output.is_relative_to(resolved_checkpoint_path)
    ):
        raise ValueError(
            "Catalog output and checkpoint paths must be separate, non-nested "
            "locations."
        )
    checkpoint = _CatalogCheckpointStore.open(
        resolved_checkpoint_path,
        run_spec=_checkpoint_run_spec(
            nct_ids=normalized_ids,
            config=resolved_config,
            settings=resolved_settings,
            sources=resolved_sources,
            role_resolver=role_resolver,
            synthesizer=synthesizer,
            class_resolver=class_resolver,
            ncit_resource=ncit_resource,
            ncit_version=ncit_version,
        ),
        reset=reset_checkpoint,
    )
    timeout = httpx.Timeout(max(1.0, resolved_settings.request_timeout))
    # Request limits are per IP, so every stage and every concurrent subject
    # draws on one shared budget per host rather than pacing itself.
    host_limiter = HostRateLimiter(host_rates)
    ctgov_rows: list[dict[str, Any]] = []
    attempts: list[ResearchAttempt] = []
    studies: dict[str, Mapping[str, Any]] = {}
    interventions_by_trial: dict[str, tuple[_CtgovIntervention, ...]] = {}
    async with paced_client(host_limiter, timeout=timeout) as client:
        for index, trial_id in enumerate(normalized_ids, start=1):
            checkpoint_input = {"trial_id": trial_id}
            saved = checkpoint.load("ctgov", trial_id, input_value=checkpoint_input)
            if saved is None:  # a checkpoint written before "registry" became "ctgov"
                saved = checkpoint.load("registry", trial_id, input_value=checkpoint_input)
            prior_attempts: list[ResearchAttempt] = []
            study: Mapping[str, Any] | None = None
            ctgov_row: dict[str, Any] | None = None
            resumed = False
            if saved is not None:
                prior_attempts = [
                    _attempt_from_record(value)
                    for value in saved.get("attempts", [])
                    if isinstance(value, Mapping)
                ]
                raw_study = saved.get("study")
                raw_row = saved.get("ctgov_row", saved.get("registry_row"))
                if isinstance(raw_row, Mapping):
                    raw_row = {_LEGACY_CTGOV_COLUMNS.get(key, key): value for key, value in raw_row.items()}
                if (
                    isinstance(raw_study, Mapping)
                    and isinstance(raw_row, Mapping)
                    and str(raw_row.get("ctgov_status") or "") == "ok"
                ):
                    study = raw_study
                    ctgov_row = dict(raw_row)
                    resumed = True
            if not resumed:
                study, new_attempts = await _fetch_ctgov_with_retries(
                    trial_id, client=client, settings=resolved_settings
                )
                trial_attempts = [*prior_attempts, *new_attempts]
                ctgov_row = _ctgov_row(trial_id, study)
                checkpoint.save(
                    "ctgov",
                    trial_id,
                    input_value=checkpoint_input,
                    data={
                        "ctgov_row": ctgov_row,
                        "study": study,
                        "attempts": [item.to_record() for item in trial_attempts],
                    },
                )
            else:
                trial_attempts = prior_attempts
            attempts.extend(trial_attempts)
            if ctgov_row is None:
                raise RuntimeError(
                    f"ctgov checkpoint produced no row for {trial_id}."
                )
            ctgov_rows.append(ctgov_row)
            if study is not None:
                studies[trial_id] = study
                interventions_by_trial[trial_id] = _extract_ctgov_interventions(
                    trial_id, study
                )
            if progress_callback:
                suffix = " (checkpoint)" if resumed else ""
                progress_callback(
                    "ctgov", index, len(normalized_ids), f"{trial_id}{suffix}"
                )

    screening_inputs = {
        trial_id: items for trial_id, items in interventions_by_trial.items() if items
    }
    role_outputs: dict[str, Mapping[str, Mapping[str, Any]]] = {}
    pending_roles: dict[str, tuple[_CtgovIntervention, ...]] = {}
    screening_completed = 0
    for trial_id, items in screening_inputs.items():
        checkpoint_input = {
            "trial_id": trial_id,
            "interventions": [asdict(item) for item in items],
        }
        saved = checkpoint.load(
            "intervention_screening", trial_id, input_value=checkpoint_input
        )
        saved_output = saved.get("output") if saved is not None else None
        if isinstance(saved_output, Mapping):
            normalized_output = {
                str(key): value
                for key, value in saved_output.items()
                if isinstance(value, Mapping)
            }
        else:
            normalized_output = {}
        if _role_output_is_complete(items, normalized_output):
            role_outputs[trial_id] = normalized_output
            screening_completed += 1
            if progress_callback:
                progress_callback(
                    "screening",
                    screening_completed,
                    len(screening_inputs),
                    f"{trial_id} (checkpoint)",
                )
        else:
            pending_roles[trial_id] = items

    def record_screening(
        trial_id: str, output_value: Mapping[str, Mapping[str, Any]]
    ) -> Mapping[str, Mapping[str, Any]]:
        """Checkpoint a valid screen, or fail it closed; return what stands."""

        nonlocal screening_completed
        items = pending_roles[trial_id]
        if _role_output_is_complete(items, output_value):
            checkpoint.save(
                "intervention_screening",
                trial_id,
                input_value={
                    "trial_id": trial_id,
                    "interventions": [asdict(item) for item in items],
                },
                data={"output": dict(output_value)},
            )
            screening_completed += 1
            if progress_callback:
                progress_callback(
                    "screening", screening_completed, len(screening_inputs), trial_id
                )
            return output_value
        # Not checkpointed, so a resumed build screens the trial again.
        validation_error = _role_output_validation_error(items, output_value)
        fallback_output = _fail_closed_role_output(
            items,
            output_value,
            validation_error=validation_error or "no parsed result",
        )
        screening_completed += 1
        if progress_callback:
            progress_callback(
                "screening",
                screening_completed,
                len(screening_inputs),
                f"{trial_id} (fail-closed: "
                f"{validation_error or 'no parsed result'})",
            )
        return fallback_output

    if role_resolver is None:
        # Trials in flight with a remote backend; the group size with a local one.
        role_batch_size = max(
            1, int(catalog_config.get("screening_checkpoint_batch_size", 64))
        )
        if remote_enabled(resolved_config):
            screening_executor = ThreadPoolExecutor(
                max_workers=role_batch_size, thread_name_prefix="catalog-screening"
            )
            run_screening = _executor_llm_runner(
                screening_executor, config=resolved_config, stage="screening"
            )

            async def screen_one(trial_id: str) -> Mapping[str, Mapping[str, Any]]:
                output_value = await _resolve_trial_roles_with_default_llm(
                    trial_id,
                    pending_roles[trial_id],
                    config=resolved_config,
                    run_messages=run_screening,
                )
                return record_screening(trial_id, output_value)

            try:
                screened = await _gather_units_continuously(
                    list(pending_roles),
                    screen_one,
                    limit=role_batch_size,
                    stage="screening",
                )
            finally:
                # A cancelled build must not wait for in-flight answers.
                screening_executor.shutdown(wait=False, cancel_futures=True)
            role_outputs.update(zip(pending_roles, screened, strict=True))
        else:
            pending_role_items = list(pending_roles.items())
            for start in range(0, len(pending_role_items), role_batch_size):
                role_batch = dict(pending_role_items[start : start + role_batch_size])
                new_role_outputs = await _resolve_roles_with_default_llm(
                    role_batch, config=resolved_config
                )
                completed_screening: set[str] = set()
                for trial_id, output_value in new_role_outputs.items():
                    if not _role_output_is_complete(
                        pending_roles[trial_id], output_value
                    ):
                        continue
                    role_outputs[trial_id] = record_screening(trial_id, output_value)
                    completed_screening.add(trial_id)
                for trial_id in sorted(set(role_batch) - completed_screening):
                    role_outputs[trial_id] = record_screening(
                        trial_id, new_role_outputs.get(trial_id, {})
                    )
    else:
        for trial_id, items in pending_roles.items():
            output_value = await _maybe_await(role_resolver(trial_id, items))
            if not isinstance(output_value, Mapping):
                output_value = {}
            checkpoint_input = {
                "trial_id": trial_id,
                "interventions": [asdict(item) for item in items],
            }
            validation_error = _role_output_validation_error(items, output_value)
            if validation_error is not None:
                raise ValueError(
                    f"Custom intervention screen returned an invalid result for "
                    f"{trial_id}: {validation_error}."
                )
            checkpoint.save(
                "intervention_screening",
                trial_id,
                input_value=checkpoint_input,
                data={"output": dict(output_value)},
            )

    def validate_good_option_catalog(path: str | Path) -> dict[str, Any]:
    """Validate file hashes, identities, roles, and terminal research states."""

    root = Path(path).expanduser().resolve()
    manifest_path = root / "manifest.json"
    if not manifest_path.is_file():
        raise ValueError(f"Catalog is missing manifest.json: {root}")
    manifest = json.loads(manifest_path.read_text(encoding="utf-8"))
    files = manifest.get("files")
    if not isinstance(files, Mapping) or not files:
        raise ValueError("Catalog manifest declares no files.")
    if manifest.get("compatibility_id") != catalog_content_id(files):
        raise ValueError("Catalog compatibility ID does not match its file hashes.")
    for relative, metadata in files.items():
        target = root / relative
        if not target.is_file():
            raise ValueError(f"Catalog is missing declared file: {relative}")
        if _sha256_file(target) != metadata.get("sha256"):
            raise ValueError(f"Catalog file hash mismatch: {relative}")
    ctgov = _read_table(root, "trial_ctgov.parquet")
    screening = _read_table(root, "trial_intervention_screening.parquet")
    index = _read_table(root, "trial_drug_index.parquet")
    summaries = pd.read_parquet(root / "drug_summaries.parquet")
    evidence = _read_evidence(root)
    drug_classes = pd.read_parquet(root / "drug_classes.parquet")
    class_summaries = pd.read_parquet(root / "class_summaries.parquet")
    class_evidence = _read_evidence(root, directory="class_evidence")
    declared_trial_ids = manifest.get("trial_ids")
    if declared_trial_ids is not None and list(ctgov["trial_id"].astype(str)) != [
        str(value) for value in declared_trial_ids
    ]:
        raise ValueError("Catalog trial_ids do not match trial_ctgov row order.")
    if ctgov["trial_id"].astype(str).duplicated().any():
        raise ValueError("trial_ctgov contains duplicate trial_id values.")
    required_screening_columns = {
        "trial_id",
        "intervention_index",
        "ctgov_name",
        "research_disposition",
        "included",
        "exclusion_category",
        "role",
        "active_entity_names_json",
    }
    missing_screening_columns = sorted(
        required_screening_columns - set(screening.columns)
    )
    if missing_screening_columns:
        raise ValueError(
            "trial_intervention_screening is missing columns: "
            + ", ".join(missing_screening_columns)
        )

        if screening[["trial_id", "intervention_index"]].astype(str).duplicated().any():
            raise ValueError(
                "trial_intervention_screening contains duplicate intervention rows."
            )

            ctgov["trial_id"].astype(str)

            raise ValueError(
                "trial_intervention_screening references unknown trial IDs."
            )

            - INTERVENTION_SCREENING_DISPOSITIONS
        )
        if unknown_dispositions:
            raise ValueError(
                "trial_intervention_screening contains unknown dispositions: "
                f"{unknown_dispositions}"

            set(screening["exclusion_category"].astype(str))
            - INTERVENTION_EXCLUSION_CATEGORIES
        )
        if unknown_categories:
            raise ValueError(
                "trial_intervention_screening contains unknown exclusion categories: "
                f"{unknown_categories}"
            )

            set(screening["role"].astype(str)) - DRUG_ROLES
        )
        if unknown_screening_roles:
            raise ValueError(
                "trial_intervention_screening contains unknown roles: "
                f"{unknown_screening_roles}"

                "trial_intervention_screening included flags do not match dispositions."
            )

            names = json.loads(str(record.get("active_entity_names_json") or "[]"))
            if not isinstance(names, list):
                raise ValueError(

            is_included = str(record.get("research_disposition")) == "include"
            if is_included != bool(names):
                raise ValueError(
                    "Included intervention screens require active entity names, and "
                    "excluded screens must not contain them."
                )

            raise ValueError("trial_drug_index contains duplicate trial-drug pairs.")
        unknown_roles = sorted(set(index["role"].astype(str)) - DRUG_ROLES)
        if unknown_roles:
            raise ValueError(
                f"trial_drug_index contains unknown roles: {unknown_roles}"
            )
        if set(index["trial_id"].astype(str)) - set(ctgov["trial_id"].astype(str)):
            raise ValueError("trial_drug_index references unknown trial IDs.")

            screening.loc[
                screening["included"].astype(bool), ["trial_id", "ctgov_name"]

            .astype(str)
            .itertuples(index=False, name=None)

            index[["trial_id", "ctgov_name"]]
            .astype(str)
            .itertuples(index=False, name=None)

                "agent screening."

        raise ValueError("drug_summaries contains duplicate drug_id values.")
    if set(index.get("drug_id", pd.Series(dtype=str)).astype(str)) - set(
        summaries["drug_id"].astype(str)

        raise ValueError("trial_drug_index references unknown drug IDs.")

    if not terminal.all():
        raise ValueError(

        )

    if not synthesis_status.isin({"ok", "blocked"}).all():

    if research_blocked_but_synthesized.any():
        raise ValueError("A research-blocked drug cannot have a completed synthesis.")
    synthesized = synthesis_status.eq("ok")
    invalid_projection = synthesized & (
        summaries["good_option_summary"].fillna("").astype(str).str.strip().eq("")
        | summaries["help_me_choose_summary"].fillna("").astype(str).str.strip().eq("")
    )
    if invalid_projection.any():
        raise ValueError(
            "Every completed synthesis requires both clean summary projections."
        )
    known_drugs = set(summaries["drug_id"].astype(str))
    evidence_drugs = set(evidence.get("drug_id", pd.Series(dtype=str)).astype(str))
    if evidence_drugs - known_drugs:
        raise ValueError("drug_evidence references unknown drug IDs.")
    for name, frame in (("drug_evidence", evidence), ("class_evidence", class_evidence)):
        unknown_scopes = sorted(
            set(frame.get("query_scope", pd.Series(dtype=str)).astype(str))
            - set(QUERY_SCOPES)
        )
        if unknown_scopes:
            raise ValueError(f"{name} contains unknown query scopes: {unknown_scopes}")
    evidence_ids_by_drug = (
        {
            drug_id: set(group["evidence_id"].astype(str))
            for drug_id, group in evidence.groupby("drug_id", sort=False)
        }
        if not evidence.empty
        else {}
    )
    for row in summaries.loc[synthesized].to_dict(orient="records"):
        facts = json.loads(str(row.get("structured_facts_json") or "{}"))
        if not isinstance(facts, Mapping):
            raise ValueError("structured_facts_json must contain a JSON object.")
        known_evidence = evidence_ids_by_drug.get(str(row["drug_id"]), set())
        for category in _SYNTHESIS_CATEGORIES:
            for fact in facts.get(category, []) or []:
                if not isinstance(fact, Mapping):
                    raise ValueError("Structured summary facts must be JSON objects.")
                if str(fact.get("scope") or "") != "agent":
                    raise ValueError(
                        "Drug summary facts must carry scope='agent'; a fact without "
                        "a scope cannot be told apart from class evidence."
                    )
                support_ids = fact.get("support_ids", []) or []
                if not isinstance(support_ids, Sequence) or isinstance(
                    support_ids, (str, bytes)
                ):
                    raise ValueError("Structured fact support_ids must be an array.")
                unsupported = set(map(str, support_ids)) - known_evidence
                if unsupported:
                    raise ValueError(
                        "Structured summary references unknown evidence IDs: "
                        + ", ".join(sorted(unsupported))
                    )
    _validate_class_tables(
        drug_classes=drug_classes,
        class_summaries=class_summaries,
        class_evidence=class_evidence,
        known_drugs=known_drugs,
    )
    return manifest

    def score_good_options_with_llm(
    candidate_pairs: pd.DataFrame,
    *,
    catalog: GoodOptionCatalog | None = None,
    research: Any = None,
    config: MMAIConfig | None = None,
    max_parse_attempts: int = 1,
    reasoning_off_fallback: bool = False,
    return_metadata: bool = False,
) -> pd.DataFrame | tuple[pd.DataFrame, dict[str, Any]]:
    """Apply the four-point rubric to a trial's catalog drug and class evidence.

    Evidence is re-rendered from the catalog's structured facts and packed to the
    teacher's context window; see :func:`pack_good_option_evidence`.

    Parse retries are selective: only invalid generations are submitted again.
    Each retry includes the prior invalid answer and the code validator's exact
    error. If requested, one additional attempt disables model thinking after
    all ordinary parse attempts have failed.
    """

    resolved_catalog = _require_catalog(catalog, research=research)
    resolved_config = config or load_default_preset()
    parse_attempts = int(max_parse_attempts)
    if parse_attempts < 1:
        raise ValueError("max_parse_attempts must be at least 1.")
    frame = _candidate_records(candidate_pairs)
    rows: list[dict[str, Any] | None] = [None] * len(frame)
    message_indices: list[int] = []
    base_messages_by_index: dict[int, list[dict[str, str]]] = {}
    messages_by_index: dict[int, list[dict[str, str]]] = {}
    summaries_by_index: dict[int, tuple[DrugSummary, ...]] = {}
    packing_by_index: dict[int, dict[str, Any]] = {}
    render_cache: dict[tuple[str, ...], str] = {}
    for index, source in frame.iterrows():
        trial_id = str(source["trial_id"])
        status = resolved_catalog.trial_status(trial_id)
        assignments = resolved_catalog.assignments_for_trial(
            trial_id, scoreable_only=True
        )
        if status != "ok":
            rows[index] = _empty_result_row(
                patient_id=str(source["patient_id"]),
                trial_id=trial_id,
                method="llm",
                status=status,
                drug_count=len(assignments),
            )
            continue
        summaries = resolved_catalog.scoreable_summaries_for_trial(trial_id)
        summaries_by_index[index] = summaries
        base_messages, packing = _build_good_option_messages(
            patient_summary=str(source["cancer_history_summary"]),
            drug_summaries=summaries,
            class_evidence=resolved_catalog.class_evidence_for_trial(trial_id),
            config=resolved_config,
            render_cache=render_cache,
        )
        packing_by_index[index] = packing
        base_messages_by_index[index] = base_messages
        messages_by_index[index] = base_messages
        message_indices.append(index)
    generation: LLMGenerationResult | None = None
    latest_by_index: dict[int, tuple[ParsedGoodOptionResult, str, str, str]] = {}
    attempts_by_index: dict[int, int] = {}
    fallback_indices: set[int] = set()
    pending_indices = list(message_indices)

    def run_pending(
        indices: Sequence[int], *, generation_config: MMAIConfig
    ) -> list[int]:
        nonlocal generation
        wave_messages = [messages_by_index[index] for index in indices]
        generation = _run_good_option_llm(
            wave_messages,
            config=generation_config,
        )
        if len(generation.final_outputs) != len(wave_messages):
            raise RuntimeError("GoodOption LLM returned an unexpected output count.")
        failed: list[int] = []
        for output_index, frame_index in enumerate(indices):
            attempts_by_index[frame_index] = attempts_by_index.get(frame_index, 0) + 1
            response = str(generation.final_outputs[output_index] or "")
            reasoning = (
                str(generation.reasoning_outputs[output_index] or "")
                if output_index < len(generation.reasoning_outputs)
                else ""
            )
            finish_reason = (
                str(generation.finish_reasons[output_index] or "")
                if output_index < len(generation.finish_reasons)
                else ""
            )
            parsed = _parse_good_option_generation(
                response,
                finish_reason=finish_reason,
                drug_summaries=summaries_by_index[frame_index],
            )
            latest_by_index[frame_index] = (
                parsed,
                response,
                reasoning,
                finish_reason,
            )
            if parsed.status == "ok":
                continue
            messages_by_index[frame_index] = _append_good_option_retry_feedback(
                base_messages_by_index[frame_index],
                response=response,
                parse_error=parsed.parse_error,
                finish_reason=finish_reason,
            )
            failed.append(frame_index)
        return failed

    for _attempt in range(parse_attempts):
        if not pending_indices:
            break
        pending_indices = run_pending(
            pending_indices,
            generation_config=resolved_config,
        )

    if pending_indices and reasoning_off_fallback:
        fallback_indices.update(pending_indices)
        pending_indices = run_pending(
            pending_indices,
            generation_config=_good_option_reasoning_disabled_config(resolved_config),
        )

    for frame_index in message_indices:
        source = frame.iloc[frame_index]
        parsed, response, reasoning, finish_reason = latest_by_index[frame_index]

    def pack_good_option_evidence(
    drug_summaries: Sequence[DrugSummary],
    class_evidence: Sequence[TrialClassEvidence] = (),
    *,
    max_chars: int | None = None,
    max_drug_chars: int | None = None,
    max_class_chars: int | None = None,
    render_cache: MutableMapping[tuple[str, ...], str] | None = None,
) -> tuple[str, list[dict[str, Any]]]:
    """Fit a trial's drug and class evidence into one prompt budget.

    Each drug and class is re-rendered from its structured facts, so how much
    detail it gets follows how much evidence the trial has to integrate rather
    than a fixed per-summary cap set when the catalog was built. A trial with one
    drug and one class shows everything; a trial with many large classes shares
    the budget by weighted fair share, with drugs weighted ahead of classes.

    A subject whose share is below its full render steps down to a coarser
    granularity (shorter attribution and statements) if that fits, which keeps
    every fact visible. Subjects that fit at a coarser level release the rest of
    their share to the others. Only when even the coarsest render overflows does
    ranked truncation drop facts, weakest evidence first, with an omission
    count; the survivors are then rendered at ``condensed`` detail so the
    strongest results keep their numbers. ``max_drug_chars`` and
    ``max_class_chars`` bound any one subject.

    Rendering is patient-independent, so callers packing many prompts from one
    catalog can pass the same ``render_cache`` to reuse whole-subject renders.

    Returns the evidence text and one record per subject describing its demand,
    budget, rendered size and granularity.
    """

    subjects = _evidence_subjects(drug_summaries, class_evidence)
    if not subjects:
        return "", []
    cache = {} if render_cache is None else render_cache

    def whole(subject: _EvidenceSubject, level: str) -> str:
        key = (subject.kind, subject.subject_id, subject.label, level)
        if key not in cache:
            cache[key] = _render_subject(
                subject, granularity=level, max_chars=_UNBOUNDED_CHARS
            )
        return cache[key]

    levels = tuple(EVIDENCE_GRANULARITIES)
    lengths = [
        {level: len(whole(subject, level)) for level in levels}
        for subject in subjects
    ]
    caps = [
        (max_class_chars if subject.kind == "class" else max_drug_chars)
        for subject in subjects
    ]
    ceilings = [
        length["full"] if cap is None else min(length["full"], max(1, int(cap)))
        for length, cap in zip(lengths, caps, strict=True)
    ]
    weights = [_SUBJECT_WEIGHTS[subject.kind] for subject in subjects]
    separators = len(_SUBJECT_SEPARATOR) * (len(subjects) - 1)
    available = (
        sum(ceilings)
        if max_chars is None
        else max(0, int(max_chars) - separators)
    )

    def fitting_level(index: int, budget: int) -> str | None:
        return next(
            (level for level in levels if lengths[index][level] <= budget), None
        )

    # Demands only fall, each subject at most once per coarser level, so this
    # settles in a few rounds.
    demands = list(ceilings)
    for _round in range(len(levels) * len(subjects) + 1):
        budgets = _weighted_fair_shares(demands, weights, available)
        changed = False
        for index, budget in enumerate(budgets):
            if budget >= demands[index]:
                continue
            level = fitting_level(index, budget)
            if level is not None and lengths[index][level] < demands[index]:
                demands[index] = lengths[index][level]
                changed = True
        if not changed:
            break

    sections: list[str] = []
    report: list[dict[str, Any]] = []
    for index, (subject, budget) in enumerate(zip(subjects, budgets, strict=True)):
        level = fitting_level(index, budget)
        truncated = level is None
        level = level or _OVERFLOW_GRANULARITY
        text = (
            _render_subject(subject, granularity=level, max_chars=budget)
            if truncated
            else whole(subject, level)
        )
        sections.append(text)
        report.append(
            {
                "kind": subject.kind,
                "name": subject.name,
                "full_chars": lengths[index]["full"],
                "budget_chars": budget,
                "rendered_chars": len(text),
                "granularity": level,
                "truncated": truncated,
                "from_structured_facts": bool(subject.facts),
            }
        )
    return _SUBJECT_SEPARATOR.join(sections), report

    expected = tuple(summary.preferred_name for summary in drug_summaries)
    if not expected:
