    Extraction-Based Workup Checks¶

    Review aids, not determinations

    Results say whether structured items extracted from the notes document a guideline workup step. An LLM wrote the query and an LLM extracted the items: check every cited quote against its note. Not documented means no extracted item matched, not that the step was not done. This does not establish overall guideline concordance.

    This is a second way to check guideline workup, beside the note-reading reviews (review_patient_workup, review_population_workup). It reads the records of Structured Clinical Extraction instead of the notes:

    1. Compile once per requirement. compile_workup_queries asks the workup_query_compile LLM to translate each guideline diagnostic_workup item (name, conditions, category), with the guideline population's key criteria as context, into a declarative JSON query. The model's only power is answering with a query: it has no tools, browsing, files or shell, and it never sees patient data. Code validates the query; an invalid answer is retried with its problems named.
    2. Evaluate in code. check_workup_with_extractions runs every query on every patient's extraction items. The evaluator is pure Python with no I/O and no model calls: the same query and records always give the same result.
    from matchminer_ai import load_default_preset
from matchminer_ai.patients import (
    check_workup_with_extractions,
    compile_workup_queries,
    extract_document_records,
)

config = load_default_preset()
config.remote.update(enabled=True, server_urls=["http://localhost:8000/v1"],
                     request_timeout=14400)

compiled = compile_workup_queries(
    space["diagnostic_workup"], config=config,
    population_context=space["cohort_key_criteria"], cache=my_cache,
)
documents = extract_document_records(notes, config=config)
report = check_workup_with_extractions(documents, compiled)

    SQL-Agent Workup Checks read the same records with queries that an LLM agent writes in SQL after exploring the extracted data.

    For a population, matchminer_ai.population.check_population_workup_with_extractions takes a cohort (with its space), the compiled queries and the document and patient records, links records to the cohort's own notes by note id, and returns the cohort with a report in the shape of the full-note population review (method extraction_queries).

    The query language¶

    A query is one JSON object, decoded under query_response_schema() with vLLM structured outputs and validated by validate_workup_query(). The schema is strict and non-recursive (no $ref, null, minLength or pattern).

    Key Meaning
    summary One sentence: what the query checks.
    expressible false when the item types cannot check the requirement (examinations, laboratory panels, consultations, multidisciplinary evaluation, counseling). Then criteria is [], every expression is {"all_of": []} and not_expressible_reason says why; the result is unknown.
    approximations What was left out or approximated ("upper abdomen" by the abdomen region). Shown as limitations.
    criteria Up to 24 named matchers of one item type each: id, label, item_type, status (performed, planned, any), filters, window, min_count.
    requirement What must be documented.
    applies_when Documented facts that make a conditional step apply ({"all_of": []}: the whole population).
    not_applicable_when Documented facts that make it not apply. It needs at least one criterion that is not negated: a step is never not applicable because something is undocumented.

    Expressions are AND-of-OR, with up to 24 groups of up to 12 literals: {"all_of": [{"any_of": [{"criterion": "id", "negated": false}, ...]}, ...]}. Alternatives are literals of one group; components that are all required are separate groups; a negated literal holds when its criterion does not. A requirement needs at least one criterion that is not negated, and every criterion must be used.

    A filter is {"field", "op", "values", "if_not_stated"}; all of a criterion's filters must hold. Fields are the item type's fields (record_json_schema), level, document_type, relation (imaging studies and procedures) and procedure_group. Operators:

    Operator Fields Holds when
    in, not_in codes the code is (is not) one of values
    contains_any, contains_all, contains_none lists of codes (body_regions) the list contains any, all or none of values
    text_contains_any, text_contains_none text, text lists a value occurs as a whole word or phrase, ignoring case and punctuation (ALK does not match "alkaline"; PD-L1 matches "PD L1")
    text_equals_any text, text lists the text equals a value, ignoring case and punctuation
    stage_group_in stage_group the stage's main group (0, I-IV, read from "IIIA", "Stage IVB" or "4") is in values
    number_at_least, number_at_most integers compared with values[0]
    is_stated any the field has a value (values is [])

    Choice values must be the field's vocabulary codes. if_not_stated decides what a filter means for an item whose field was not stated (not_stated, "", [], or a line_of_therapy of 0): unknown (the usual choice), no_match or match.

    A window is {"anchor", "anchor_criterion", "days_before", "days_after", "if_no_anchor"}: the item's date must lie from days_before days before the anchor to days_after days after it (-1: no limit; 0: not after or not before). Anchors are any_time (no limit; both days -1), reference_date (the evaluation date, by default the patient's latest note date), diagnosis_date (the earliest dated extracted diagnosis, or a supplied one), and criterion_earliest / criterion_latest (the earliest or latest certain match of another criterion, such as the first systemic therapy; anchors may not form a cycle). if_no_anchor is unknown, or reference_date to use the evaluation date when the anchor does not exist (a patient not yet treated). An anchor that may exist but is undated or only possibly matched is unknown and never replaced by the evaluation date; an undated certain match makes the earliest anchor's interval open-ended.

    Example: a brain MRI, or a contrast head CT, before the first systemic therapy, when stage III-IV is documented:

    {
  "summary": "Brain MRI or head CT before the first systemic therapy, if stage III-IV.",
  "expressible": true, "not_expressible_reason": "",
  "approximations": ["Whether MRI was possible is not extracted; head CT is accepted."],
  "criteria": [
    {"id": "brain_mri", "label": "Brain MRI", "item_type": "imaging_study", "status": "performed",
     "filters": [{"field": "modality", "op": "in", "values": ["mri"], "if_not_stated": "no_match"},
                 {"field": "body_regions", "op": "contains_any", "values": ["brain"], "if_not_stated": "unknown"}],
     "window": {"anchor": "criterion_earliest", "anchor_criterion": "systemic", "days_before": -1,
                "days_after": 0, "if_no_anchor": "reference_date"}, "min_count": 1},
    {"id": "systemic", "label": "Systemic therapy", "item_type": "treatment", "status": "performed",
     "filters": [{"field": "treatment_type", "op": "in", "values": ["systemic_therapy"], "if_not_stated": "no_match"}],
     "window": {"anchor": "any_time", "anchor_criterion": "", "days_before": -1, "days_after": -1,
                "if_no_anchor": "unknown"}, "min_count": 1},
    "... head_ct, stage_3_4 and stage_0_2 criteria ..."
  ],
  "applies_when": {"all_of": [{"any_of": [{"criterion": "stage_3_4", "negated": false}]}]},
  "not_applicable_when": {"all_of": [{"any_of": [{"criterion": "stage_0_2", "negated": false}]},
                                     {"any_of": [{"criterion": "stage_3_4", "negated": true}]}]},
  "requirement": {"all_of": [{"any_of": [{"criterion": "brain_mri", "negated": false},
                                         {"criterion": "head_ct", "negated": false}]}]}
}

    How results are evaluated¶

    Each test is yes, unknown or no, combined with Kleene logic (AND takes the lower, OR the higher, NOT swaps yes and no).

    Dates are intervals of days:

    Item date Interval
    day precision (written, or a report's own study dated by its note) that day
    month or year precision every day of that month or year
    evidence_note_date (a patient-level study dated by its earliest evidence note) on or before that date
    unknown, document level (for example previously_performed with no date) on or before the note's date
    unknown, planned on or after the note's date
    unknown, patient level on or before its earliest evidence note

    An item is inside a window when its whole interval is, outside when none of it is, and unknown otherwise; anchors are intervals too. So a month-precision CT is unknown against "within 30 days" unless the whole month fits, and an undated "outside CT was done" mention counts for "any time" but is unknown against a recent window.

    Deduplication. The same study, procedure, result or course documented in several notes, or at both levels, is one cluster: same item type and kind (for imaging, the modality and overlapping body regions; for procedures, the procedure type; for biomarkers, the marker, result and alteration; for treatments, the type and agents or regimen), compatible dates and the same performed or planned status. An undated or less precise mention joins the most recent compatible dated cluster. A cluster is dated by its most precise member, and passes a filter when a member does, except that the report's own study (this_report) decides when it contradicts a mention. Criteria count clusters: a CT report and a later note mentioning that CT count once.

    Criteria. A criterion holds when at least min_count clusters certainly match (status, filters and window), is unknown when enough clusters might, and does not hold otherwise. Planned items never satisfy performed.

    Status and applicability:

    Status When reason
    met the requirement holds documented
    not_met no extracted item documents it not_documented, or planned_only when only planned or ordered items match
    unknown a matching item's date or details leave it open, its anchor is missing, some of the patient's notes failed extraction or have no record, there are no records, or the requirement is not expressible uncertain_dates, fields_not_stated, anchor_unavailable, incomplete_extraction, no_extraction, not_expressible, query_unavailable
    not_applicable not_applicable_when holds documented_not_applicable

    applicability is applies (no condition, or applies_when holds), not_applicable (documented contrary facts) or uncertain (the condition is not documented, or the facts conflict). Not applicable always needs documented facts.

    Each result also carries a machine-made bottom_line (for example "Met: CT chest: CT (chest, abdomen, pelvis), with contrast, 2024-03-02 (day precision, dated by its report, note note-1a2b)"), every criterion's certain and possible counts and anchor, the matching clusters with their dates and mentions, the closest_non_matches (items of the same kind, such as the same modality or marker, that failed only some filters or the window, with what differed; a not-documented explanation names the closest one), and the evidence quotes with their note_id, note_date and character offsets. Matches are listed certain first, then precisely dated before undated mentions, then most recent. aggregate_extraction_workup counts statuses, applicability and reasons per requirement; met / applicable assessed counts met among patients it applies to whose result is met or not met.

    Compile settings, retries and caching¶

    The workup_query_compile preset section defaults to Nemotron 3.5 Super with sampling_profile: auto, thinking on and structured outputs, 40,000 output tokens in a 131,072-token context (its prompt is about 8,000 tokens). An answer that is not complete JSON or fails validation is retried with its problems named (max_attempts: 3), then once with thinking off (reasoning_off_fallback): three retries in all. Each entry records its attempts (finish reasons and problems, no reasoning) and first_attempt_valid.

    Distinct requirements are compiled once per call. Pass cache (any mapping, such as a dict or a folder of JSON files) to reuse compilations across calls: the key (workup_query_cache_key) covers the requirement's name, conditions and category, the population context, the extraction schema version, the query language version (mmai-workup-query-v1), and the prompt and response-schema hashes. A cached query is validated again before use. Compiled queries contain guideline text only.

    matchminer_ai.patients.workup_queries ¶

    Extraction-based workup checks: guideline requirements as queries over extracted items.

    A research review aid beside the note-reading workup reviews (:func:~matchminer_ai.patients.review_patient_workup): an LLM compiles each guideline workup requirement once into a declarative JSON query (:func:compile_workup_queries; its only power is returning the query), code validates it, and code evaluates it deterministically on every patient's structured extraction records (:func:check_workup_with_extractions), with no I/O and no model calls. Results are met, not met (not documented), unknown or not applicable, each with the matching items, their dates and evidence quotes, and a machine-made explanation. They need human review against the source notes.

    def compile_workup_queries(
    requirements: Sequence[dict],
    *,
    config: MMAIConfig | None = None,
    population_context: str | None = None,
    cache: MutableMapping[str, dict] | None = None,
    extensions: Iterable[str] | None = None,
    progress_callback: Callable[[int, int], None] | None = None,
    return_metadata: bool = False,
) -> list[dict] | tuple[list[dict], dict]:
    """Compile each workup requirement into a validated query.

    ``requirements`` are guideline ``diagnostic_workup`` items (``name``,
    ``conditions``, ``category``; other keys are ignored). ``population_context``
    is the guideline population's key criteria, shown to the model as context.
    Each distinct requirement is one request with ``config.workup_query_compile``;
    a cached compilation (``cache[key]`` from :func:`workup_query_cache_key`) is
    revalidated and reused without a request, and each new successful one is
    stored in ``cache``.

    Returns one entry per requirement, in order: ``requirement``, ``cache_key``,
    ``status`` (``compiled`` or ``failed``), ``query`` (None when failed),
    ``error``, ``attempts`` (finish reasons and problems; no reasoning),
    ``first_attempt_valid``, ``cached``, ``model`` and the compile ``contract``.
    No patient data is involved.
    """
    resolved = config or load_default_preset()
    if not isinstance(resolved, MMAIConfig):
        raise TypeError("config must be an MMAIConfig instance or None.")
    if population_context is not None and not isinstance(population_context, str):
        raise TypeError("population_context must be text or None.")
    texts = [requirement_text(r) for r in requirements]
    extensions = default_extensions(resolved) if extensions is None else list(extensions)
    schema = query_response_schema(extensions)
    contract = compile_contract(extensions)
    keys = [workup_query_cache_key(t, population_context, contract=contract) for t in texts]
    settings = section_settings(resolved, SECTION, "workup_query", schema)
    model = settings.runtime.get("model_name")
    progress = progress_callback or (lambda done, total: None)
    entries: dict[str, dict] = {}
    for key in dict.fromkeys(keys):
        saved = cache.get(key) if cache is not None else None
        if (
            isinstance(saved, dict)
            and saved.get("status") == "compiled"
            and saved.get("contract") == contract
            and not validate_workup_query(saved.get("query"), extensions)
        ):
            entries[key] = {**saved, "cached": True}
    pending = [(key, texts[keys.index(key)]) for key in dict.fromkeys(keys) if key not in entries]
    total, done = len(set(keys)), len(entries)
    progress(done, total)
    model_metadata: dict[str, Any] = {}
    if pending:
        queue = RequestQueue(
            get_llm_backend(resolved), settings.runtimes, chunk_size=settings.batch_size,
            chunks_in_flight=settings.batches_in_flight,
            model_metadata_cache_dir=resolved.model_metadata_cache_dir,
        )
        attempts: dict[str, list] = {}
        requirement_of = dict(pending)
        for key, text in pending:
            original = [{"role": "user", "content": render_compile_prompt(
                text, population_context, extensions=extensions)}]
            queue.add((key, 1, original), original, "main")

        def finish(key, status, query, error):
            nonlocal done
            history = attempts.get(key, [])
            entries[key] = {
                "cache_key": key,
                "requirement": requirement_of[key],
                "population_context_sha256": digest((population_context or "").strip()),
                "status": status,
                "query": query,
                "error": error,
                "attempts": history,
                "attempt_count": len(history),
                "first_attempt_valid": status == "compiled" and len(history) == 1,
                "contract": contract,
                "model": model,
                "compiled_at": datetime.now(timezone.utc).isoformat(timespec="seconds"),
                "cached": False,
            }
            if status == "compiled" and cache is not None:
                cache[key] = {k: v for k, v in entries[key].items() if k != "cached"}
            done += 1
            progress(done, total)

        def record(item, answer, reasoning, finish_reason, provenance):
            key, attempt, original = item
            group = attempt_group(attempt, settings)
            entry = attempt_entry(attempt, group, finish_reason, None, debug=False,
                                  answer=None, reasoning=None)
            attempts.setdefault(key, []).append(entry)
            if finish_reason == "error":
                entry["problems"] = ["request failed"]
                finish(key, "failed", None, "the LLM request failed after its transport retries")
                return
            try:
                value = parse_answer(answer, finish_reason)
            except ValueError as exc:
                value, problems, error = None, [], str(exc)
            else:
                problems, error = validate_workup_query(value, extensions), None
            if error is None and not problems:
                finish(key, "compiled", canonical_query(value), None)
                return
            entry["problems"] = [error] if error else problems[:_MAX_PROBLEMS]
            if attempt < settings.total_attempts:
                queue.add((key, attempt + 1, original),
                          _retry(original, answer, value is not None, problems, error),
                          attempt_group(attempt + 1, settings))
                return
            finish(key, "failed", None, "no valid query after every attempt: "
                   + "; ".join(entry["problems"][:5]))

        logger.info("Compiling %d workup queries.", len(pending))
        model_metadata = queue.run(record)
    results = [{**entries[key], "requirement": text} for key, text in zip(keys, texts, strict=True)]
    if not return_metadata:
        return results
    metadata = {
        "contract": contract,
        "model": model,
        # Cached queries keep the model that compiled them, which may differ from model.
        "compiled_by": sorted({entries[key]["model"] for key in set(keys)
                               if entries[key].get("model")}),
        "structured_outputs": settings.structured,
        "requirements": len(texts),
        "distinct": total,
        "cached": sum(1 for key in set(keys) if entries[key].get("cached")),
        "compiled": sum(1 for key in set(keys) if entries[key]["status"] == "compiled"),
        "requests": sum(entries[key].get("attempt_count", 0) for key in set(keys)
                        if not entries[key].get("cached")),
        "first_attempt_valid": sum(1 for key in set(keys) if not entries[key].get("cached")
                                   and entries[key].get("first_attempt_valid")),
        "model_metadata": {k: v for k, v in model_metadata.items() if k != "responses"},
    }
    return results, metadata

    def check_workup_with_extractions(
    records,
    compiled: Sequence[dict],
    *,
    patient_ids: Sequence[str] | None = None,
    reference_dates: Mapping[str, object] | str | None = None,
    anchors: Mapping[str, Mapping[str, object]] | None = None,
    coverage: Mapping[str, Mapping] | None = None,
) -> dict:
    """Check every compiled workup query on every patient's extraction records.

    ``records``: ``extract_document_records`` and/or ``extract_patient_records``
    output (a DataFrame or a list of them), ``extraction_items`` output, or
    record dicts. ``compiled``: :func:`compile_workup_queries` output (one entry
    per requirement, in order). ``patient_ids`` adds patients with no records
    (their results are unknown) and fixes the order. ``reference_dates`` is one
    date for everyone or dates by patient; ``anchors`` gives a patient's
    ``diagnosis_date``; ``coverage`` adds counts such as
    ``notes_without_records`` by patient.

    Returns ``{"patients": [{"patient_id", "review": {"assessments", "notice",
    "metadata"}}], "aggregate": [...], "notice"}``; each assessment carries the
    requirement, its ``status``, ``applicability``, ``reason``, ``bottom_line``,
    criteria, ``evidence`` and ``limitations``. Pure computation: no I/O.
    """
    data = patient_data(records, coverage=coverage)
    ids = [str(p) for p in patient_ids] if patient_ids is not None else sorted(data)
    if len(set(ids)) != len(ids):
        raise ValueError("patient_ids repeat")
    extensions = _all_extensions()
    queries = []
    for entry in compiled:
        query = entry.get("query") if entry.get("status") == "compiled" else None
        queries.append(check_workup_query(query, extensions) if query is not None else None)
    patients = []
    for pid in ids:
        patient = data.get(pid) or PatientData(pid)
        if isinstance(reference_dates, Mapping):
            reference = reference_dates.get(pid)
        else:
            reference = reference_dates
        assessments = []
        for number, (entry, query) in enumerate(zip(compiled, queries, strict=True)):
            result = evaluate_workup_query(query, patient, reference_date=reference,
                                           anchors=(anchors or {}).get(pid), extensions=extensions)
            assessments.append({
                "recommendation_index": number,
                "recommendation": copy.deepcopy(entry["requirement"]),
                "name": entry["requirement"]["name"],
                **result,
                "query_key": entry.get("cache_key"),
            })
        patients.append({
            "patient_id": pid,
            "review": {
                "assessments": assessments,
                "notice": NOTICE,
                "metadata": {"method": "extraction_queries", "coverage": patient.coverage()},
            },
        })
    requirements = [entry["requirement"] for entry in compiled]
    return {"patients": patients, "aggregate": aggregate_extraction_workup(patients, requirements),
            "notice": NOTICE}

    def evaluate_workup_query(
    query: dict | None,
    patient: PatientData,
    *,
    reference_date=None,
    anchors: Mapping[str, object] | None = None,
    extensions: Iterable[str] | None = None,
) -> dict:
    """Evaluate one compiled query on one patient's items (:func:`patient_data`).

    ``reference_date`` (YYYY-MM-DD) dates ``reference_date`` windows and the
    ``if_no_anchor`` fallback; it defaults to the patient's latest note date.
    ``anchors`` may supply ``diagnosis_date`` instead of the earliest extracted
    diagnosis. Returns ``status``, ``reason``, ``applicability``, a machine-made
    ``explanation``, each criterion's matches with dates and evidence, and the
    flattened ``evidence`` quotes (note id, note date, quote, character offsets).
    """
    extensions = _all_extensions() if extensions is None else list(extensions)
    if query is None:
        return _result("unknown", "query_unavailable", "uncertain",
                       "Unknown: no valid query could be compiled for this requirement.")
    query = check_workup_query(query, extensions)
    if not query["expressible"]:
        return _result("unknown", "not_expressible", "uncertain",
                       "Unknown: not checkable from extracted items ("
                       f"{query['not_expressible_reason'].strip()})", query=query)
    if not patient.has_records:
        return _result("unknown", "no_extraction", "uncertain",
                       "Unknown: no extraction records are available for this patient.",
                       query=query)
    if reference_date is None:
        reference_date = patient.last_note_date
    reference, reference_text = None, None
    if reference_date is not None:
        value, precision = parse_date(reference_date)
        if value is not None:
            reference, reference_text = date_interval(value, precision), value
    ctx = Context(patient, reference, reference_text, anchors or {},
                  criteria={c["id"]: c for c in query["criteria"]},
                  types={t.name: t for t in item_types(extensions)})
    applies, applies_groups = evaluate_expression(ctx, query["applies_when"])
    excluded, excluded_groups = (
        evaluate_expression(ctx, query["not_applicable_when"])
        if query["not_applicable_when"]["all_of"] else (NO, [])
    )
    if excluded == YES and applies == YES and query["applies_when"]["all_of"]:
        applicability = "uncertain"
    elif excluded == YES:
        applicability = "not_applicable"
    elif applies == YES:
        applicability = "applies"
    else:
        applicability = "uncertain"
    met, groups = evaluate_expression(ctx, query["requirement"])
    notes = []
    if applicability == "uncertain" and query["applies_when"]["all_of"] and applies != YES:
        notes.append("Applicability uncertain: " + "; ".join(
            _explain(ctx, applies_groups, MAYBE if applies == MAYBE else NO)) + ".")
    elif applicability == "uncertain":
        notes.append("Applicability uncertain: documented facts both support and contradict it.")
    evidence = _evidence(ctx, groups)
    if applicability == "not_applicable":
        status, reason = "not_applicable", "documented_not_applicable"
        text = "Not applicable: " + "; ".join(_explain(ctx, excluded_groups, YES)) + "."
        evidence = _evidence(ctx, excluded_groups, (YES,))
    elif met == YES:
        status, reason = "met", "documented"
        text = "Met: " + "; ".join(_explain(ctx, groups, YES)) + "."
    elif met == MAYBE:
        status = "unknown"
        found = {r for state, literals in groups if state == MAYBE for lit, s in literals
                 if s == MAYBE for r in evaluate_criterion(ctx, lit["criterion"]).reasons}
        reason = ("anchor_unavailable" if "anchor_unavailable" in found
                  else "uncertain_dates" if any("date" in r or "mention" in r or "plan" in r
                                                for r in found)
                  else "fields_not_stated")
        text = "Unknown: " + "; ".join(_explain(ctx, groups, MAYBE)) + "."
    else:
        planned = _planned(ctx, groups)
        phrases = _explain(ctx, groups, NO)
        count = sum(len(c.members) for t in ctx.by_type for c in ctx.by_type[t])
        if patient.incomplete:
            status, reason = "unknown", "incomplete_extraction"
            text = ("Unknown: not found in the extraction records (" + "; ".join(phrases)
                    + "), but " + _incomplete(patient) + ".")
        elif planned:
            status, reason = "not_met", "planned_only"
            plans = ", ".join(f"{describe_item(p.cluster.rep)} ({_date_text(p.cluster.rep)})"
                              for p in planned[:3])
            text = (f"Not documented as performed: {'; '.join(phrases)}. Planned or ordered: "
                    f"{plans}.")
            evidence = _evidence_planned(planned)
        else:
            status, reason = "not_met", "not_documented"
            text = (f"Not documented in the extraction records: {'; '.join(phrases)} "
                    f"(among {count} extracted items of the queried types). A missing item "
                    "does not mean the step was not done.")
    if notes and status != "not_applicable":
        text += " " + " ".join(notes)
    criteria = [_criterion_entry(evaluate_criterion(ctx, c["id"])) for c in query["criteria"]]
    limitations = list(query["approximations"])
    if patient.incomplete and status != "unknown":
        limitations.append(_incomplete(patient).capitalize() + ".")
    return _result(status, reason, applicability, text, query=query, criteria=criteria,
                   evidence=evidence, limitations=limitations,
                   reference_date=reference_text)

    def validate_workup_query(query, extensions: Iterable[str] | None = ()) -> list[str]:
    """Every problem of ``query``, as messages a model can act on ([] when valid)."""
    problems: list[str] = []
    if not _keys(query, _TOP, "query", problems):
        return problems
    _string(query["summary"], "summary", problems, blank=False)
    if not isinstance(query["expressible"], bool):
        problems.append("expressible: must be true or false")
        return problems
    _string(query["not_expressible_reason"], "not_expressible_reason", problems)
    notes = query["approximations"]
    if not isinstance(notes, list) or len(notes) > MAX_APPROXIMATIONS:
        problems.append(f"approximations: must be a list of at most {MAX_APPROXIMATIONS} strings")
    else:
        for i, note in enumerate(notes):
            _string(note, f"approximations[{i}]", problems, blank=False)
    criteria = query["criteria"]
    if not isinstance(criteria, list) or len(criteria) > MAX_CRITERIA:
        problems.append(f"criteria: must be a list of at most {MAX_CRITERIA} criteria")
        return problems
    if not query["expressible"]:
        if criteria:
            problems.append("criteria: must be [] when expressible is false")
        for name in _EXPRESSIONS:
            if query[name] != {"all_of": []}:
                problems.append(f"{name}: must be {{\"all_of\": []}} when expressible is false")
        if isinstance(query["not_expressible_reason"], str) and not query[
            "not_expressible_reason"
        ].strip():
            problems.append("not_expressible_reason: say why the requirement cannot be checked")
        return problems
    if isinstance(query["not_expressible_reason"], str) and query["not_expressible_reason"].strip():
        problems.append("not_expressible_reason: must be '' when expressible is true")
    types = {t.name: t for t in item_types(extensions)}
    ids: dict[str, dict] = {}
    anchors: dict[str, str] = {}
    for c, criterion in enumerate(criteria):
        path = f"criteria[{c}]"
        keys = ("id", "label", "item_type", "status", "filters", "window", "min_count")
        if not _keys(criterion, keys, path, problems):
            continue
        cid = criterion["id"]
        if not isinstance(cid, str) or not _ID.fullmatch(cid):
            problems.append(f"{path}.id: use 1-24 lowercase letters, digits or _, starting "
                            "with a letter")
        elif cid in ids:
            problems.append(f"{path}.id: {cid!r} is used twice")
        else:
            ids[cid] = criterion
        _string(criterion["label"], f"{path}.label", problems, blank=False)
        item_type = types.get(criterion["item_type"])
        if item_type is None:
            problems.append(f"{path}.item_type: must be one of {sorted(types)}")
            continue
        status = criterion["status"]
        if status not in STATUSES:
            problems.append(f"{path}.status: must be one of {list(STATUSES)}")
        elif status == "planned" and item_type.name not in STATUS_TYPES:
            problems.append(f"{path}.status: {item_type.name} items are never planned; use any")
        _integer(criterion["min_count"], f"{path}.min_count", problems, 1, MAX_COUNT)
        filters = criterion["filters"]
        if not isinstance(filters, list) or len(filters) > MAX_FILTERS:
            problems.append(f"{path}.filters: must be a list of at most {MAX_FILTERS} filters")
        else:
            fields = query_fields(item_type)
            for f, entry in enumerate(filters):
                _check_filter(entry, f"{path}.filters[{f}]", item_type, fields, problems)
        window = criterion["window"]
        where = f"{path}.window"
        wkeys = ("anchor", "anchor_criterion", "days_before", "days_after", "if_no_anchor")
        if not _keys(window, wkeys, where, problems):
            continue
        anchor = window["anchor"]
        if anchor not in ANCHORS:
            problems.append(f"{where}.anchor: must be one of {list(ANCHORS)}")
            continue
        if window["if_no_anchor"] not in NO_ANCHOR:
            problems.append(f"{where}.if_no_anchor: must be one of {list(NO_ANCHOR)}")
        before_ok = _integer(window["days_before"], f"{where}.days_before", problems, -1, MAX_DAYS)
        after_ok = _integer(window["days_after"], f"{where}.days_after", problems, -1, MAX_DAYS)
        if anchor == "any_time":
            if before_ok and after_ok and (window["days_before"], window["days_after"]) != (-1, -1):
                problems.append(f"{where}: any_time takes no day limits (use -1 and -1); for a "
                                "time limit choose an anchor such as reference_date")
        if anchor.startswith("criterion_"):
            if not isinstance(window["anchor_criterion"], str) or not window["anchor_criterion"]:
                problems.append(f"{where}.anchor_criterion: {anchor} needs a criterion id")
            elif isinstance(cid, str):
                anchors[cid] = window["anchor_criterion"]
        elif window["anchor_criterion"] != "":
            problems.append(f"{where}.anchor_criterion: must be '' unless the anchor is "
                            "criterion_earliest or criterion_latest")
    for cid, target in anchors.items():
        if target not in ids:
            problems.append(f"criteria {cid!r}: anchor_criterion {target!r} is not a criterion id")
        elif target == cid:
            problems.append(f"criteria {cid!r}: a criterion cannot anchor its own window")
    seen_cycle = set()
    for start in anchors:
        chain, node = [], start
        while node in anchors and node not in chain:
            chain.append(node)
            node = anchors[node]
        if node in chain and node not in seen_cycle and len(chain) > 1:
            seen_cycle.update(chain)
            problems.append(f"criteria {sorted(set(chain))}: anchor criteria form a cycle")
    used: set[str] = set(anchors.values())
    for name in _EXPRESSIONS:
        literals = _check_expression(query[name], name, ids, problems)
        used.update(cid for cid, _ in literals)
        if name == "requirement":
            groups = query[name].get("all_of") if isinstance(query[name], dict) else None
            if isinstance(groups, list) and not groups:
                problems.append("requirement.all_of: an expressible requirement needs at least "
                                "one group")
            elif literals and all(negated for _, negated in literals):
                problems.append("requirement: needs at least one criterion that is not negated")
        if name == "not_applicable_when" and literals and all(n for _, n in literals):
            problems.append(
                "not_applicable_when: needs a documented fact, a criterion that is not negated; "
                "a step is not applicable only when documented facts say so, never because "
                "something is not documented (leave it {\"all_of\": []} instead)")
    for cid in ids:
        if cid not in used:
            problems.append(f"criteria {cid!r}: not used by any expression or window anchor")
    return problems

    def aggregate_extraction_workup(reviews: Sequence[dict], requirements: Sequence[dict]) -> list[dict]:
    """Counts per requirement: statuses, applicability, reasons, and met among applicable.

    ``completed_applicable / applicable_assessed`` is met / (met + not met) among
    patients the requirement applies to: unknown and not-applicable results stay
    out of the denominator. It is a documentation fraction, not a concordance rate.
    A requirement that advises against a step (its assessments say
    ``recommends_against``) has no completion fraction: its ``done_not_recommended``
    count says how many patients had the step anyway.
    """
    rows = []
    for number, requirement in enumerate(requirements):
        statuses = {s: 0 for s in STATUSES}
        applicability = {a: 0 for a in APPLICABILITY}
        reasons = {r: 0 for r in REASONS}
        met = assessed = 0
        against = False
        for patient in reviews:
            items = patient["review"]["assessments"]
            if len(items) != len(requirements):
                raise ValueError("Incomplete extraction workup matrix.")
            row = items[number]
            if row["status"] not in statuses or row["applicability"] not in applicability:
                raise ValueError("Invalid extraction workup result.")
            statuses[row["status"]] += 1
            applicability[row["applicability"]] += 1
            reason = row.get("reason") or "not_documented"
            reasons[reason] = reasons.get(reason, 0) + 1
            against |= bool(row.get("recommends_against"))
            if row["applicability"] == "applies" and row["status"] in {"met", "not_met"}:
                assessed += 1
                met += row["status"] == "met"
        if against:
            met = assessed = 0
        rows.append({
            "recommendation_index": number,
            "recommendation": copy.deepcopy(requirement),
            "patient_count": len(reviews),
            "statuses": statuses,
            "applicability": applicability,
            "reasons": reasons,
            "applicable_assessed": assessed,
            "completed_applicable": met,
            "documented_completion_fraction": met / assessed if assessed else None,
            "recommends_against": against,
        })
    return rows
