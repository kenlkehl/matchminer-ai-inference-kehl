TASK
This trial evaluates a cancer treatment. List the cohorts it defines: the parts, phases, arms, or groups into which it enrolls participants. Return only their names. Each cohort's eligibility criteria are extracted afterwards in a separate request that receives this document, your list of names, and one of the names, so every name must tell a reader of this document exactly which group of people it means. You do not need to compare the cohorts' eligibility criteria. Read the whole document before answering.

Treat the terms cohort, arm, part, phase, module, stage, and group as equivalent here; "cohort" is used below for all of them.

WHERE COHORTS ARE DEFINED
-In a full protocol, cohorts may be described in the synopsis, the study design section, the study schema or flow chart, the eligibility sections, cohort- or part-specific sections or modules, appendices, tables, and footnotes. Search the whole document. The body of the protocol is authoritative over the synopsis. If the document includes an amendment history or summary of changes, use the trial as it currently stands, not deleted or superseded text quoted in change tables.
-In a registry listing, cohorts may be described in the title, the brief summary, or headings and labeled lists within the eligibility criteria.

WHICH COHORTS TO LIST
-List every cohort the document defines, including cohorts that appear only in the study design, schema, flow chart, synopsis, or an amendment, such as an expansion or backfill group, and cohorts described as closed to enrollment, fully enrolled, completed, on hold, or terminated.
-When cohorts are nested, list the lowest-level groups. For example, two phases that each contain three parts give six cohorts, one for each phase-part combination.
-Cohorts or enrollment groups that the document defines for a particular disease or subtype are separate cohorts. Do not invent subgroups that the document does not define.
-Do not list these as cohorts: dose levels or dose-escalation steps within a part, which differ only in the dose given; the arms to which participants are randomized after enrolling in one population (list that population once); stratification factors; crossover, extension, continuation, retreatment, and rollover phases, which only people already in the trial can enter; and optional sub-studies.
-A cohort that enrolls only in particular countries or regions, such as a Japan-only or China-only cohort, is listed only if those countries or regions include the United States. This includes country- or region-specific cohorts described in appendices or country-specific sections; when the whole trial enrolls in one country or region, list its cohorts as usual.
-If the trial enrolls a single group of people, return one cohort.

NAMING THE COHORTS
-Use the document's own names. For a cohort at the lowest level of nested cohorts, join the names of its levels, such as "Phase 1b, Part B".
-When the document's name alone would not tell a reader which group is meant, or the document gives no name, add a brief description of the group's defining feature taken from the document, such as its disease or treatment setting, for example "Cohort 2 (previously treated disease)". For a trial with a single cohort, use the document's name for its population or "All participants".
-Give every cohort a different name, and list the cohorts in the order the document presents them.
-Return names only; do not write eligibility criteria.

OUTPUT FORMAT
Return only one JSON object with exactly one field, "cohorts": an array of one or more cohort-name strings, for example {{"cohorts": ["Part A, dose escalation", "Part B, dose expansion (disease X)"]}}. Add no other fields, text, or Markdown fences, and end the response with the object's closing brace.
