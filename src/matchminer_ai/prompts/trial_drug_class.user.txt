You will be given the name, aliases, and mechanism passages for one cancer drug. Name the pharmacologic class or classes it belongs to.

The classes you name are used to retrieve literature about other agents that work the same way, so that a drug with thin evidence of its own can still be judged against what its class has shown. A class is therefore useful exactly when a reader would expect agents in it to behave alike in patients.

Name every distinct class the passages support, most specific first, at most {max_classes}. Drugs commonly belong to more than one: atezolizumab is both a PD-L1 inhibitor and an immune checkpoint inhibitor, and an antibody-drug conjugate belongs to a class defined by its target and another defined by its payload.

Write each class the way the literature writes it, preferring these forms so that two drugs sharing a class produce the same words:

- "<TARGET> inhibitor" for a small molecule or antibody that blocks a named target, as in "PD-L1 inhibitor" or "BRAF inhibitor"
- "<TARGET> monoclonal antibody" when the modality is what defines it, as in "CD93 monoclonal antibody"
- "<TARGET> antibody-drug conjugate", "<TARGET> degrader", "<TARGET> CAR T-cell therapy", and the like for other engineered modalities
- a mechanism family when that is what the literature shares, as in "immune checkpoint inhibitor", "tyrosine kinase inhibitor", "PARP inhibitor", "DNA damage response inhibitor"

Do not write a bare target name, a trade name, a single drug name, or a disease. Do not write "targeted therapy", "immunotherapy", "chemotherapy", "small molecule", or "monoclonal antibody" on their own; they group agents that do not behave alike.

Low confidence is a usable answer and is expected for first-in-human agents. If the passages establish only that the drug is an antibody against CD93, then "CD93 monoclonal antibody" at low confidence is the right answer. Return an empty array only when the passages say nothing about what the drug does.

Return concise JSON only, an object with one array named classes. Every item must contain:

- `name`: the class, in the canonical form above
- `basis`: "target" when the class is defined by the molecule it acts on, "mechanism" when defined by the pathway or process it acts through, "modality" when defined by how the agent is built
- `target`: the gene, protein, or pathway, or an empty string when the class has no single one
- `aliases`: other names the literature uses for this same class, for example ["anti-PD-L1 antibody", "PD-L1 blockade"]
- `confidence`: "high", "medium", or "low"
- `support_ids`: the P# identifiers of the passages that establish it

Use only supplied P# identifiers. Do not infer a class no passage supports.
